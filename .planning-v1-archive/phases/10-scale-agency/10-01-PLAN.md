1. Create `backend/app/services/brand_service.py` with BrandService class:
   - `__init__(self, db: Session)` -- store db reference
   - `create_brand(self, user_id: str, data: BrandCreate) -> Brand`:
     * Normalize domain from URL using normalize_domain()
     * Check uniqueness (user_id + domain combo). If exists, raise ValueError("Brand with this domain already exists")
     * Create Brand record, db.add + commit + refresh
     * **Retroactive association**: After creating brand, run `UPDATE audits SET brand_id = brand.id WHERE user_id = user_id AND domain = brand.domain AND brand_id IS NULL`. This makes the feature immediately useful by showing existing audit history under the new brand.
     * Return the brand
   - `list_brands(self, user_id: str) -> list[Brand]`:
     * Query Brand where user_id matches, order by created_at desc
     * For each brand, eagerly count audits (use a subquery or len(brand.audits))
     * Return list
   - `get_brand(self, brand_id: str, user_id: str) -> Brand`:
     * Query Brand where id matches AND user_id matches (ownership check -- Pitfall 4)
     * If not found, raise ValueError("Brand not found")
     * Return brand
   - `update_brand(self, brand_id: str, user_id: str, data: BrandUpdate) -> Brand`:
     * Get brand via get_brand (ownership enforced)
     * Update fields that are not None
     * If URL changed, re-normalize domain and re-run retroactive association
     * Commit + refresh, return brand
   - `delete_brand(self, brand_id: str, user_id: str) -> None`:
     * Get brand via get_brand (ownership enforced)
     * Set brand_id=NULL on all audits associated with this brand (don't delete audits)
     * Delete brand, commit
   - `get_brand_audit_count(self, brand_id: str) -> int`:
     * Count audits with this brand_id
   - `find_brand_by_domain(self, user_id: str, domain: str) -> Brand | None`:
     * Query Brand where user_id and domain match. Return first or None.

   - `DELETE /{brand_id}` -- Delete brand. 204 No Content on success. 404 if not found or not owned.
   - `GET /{brand_id}/audits` -- List audits for a specific brand (query Audit where brand_id matches, user_id matches). Return list of audit summaries (id, url, status, created_at, optimization_score, visibility_score from VisibilityScore if exists).
