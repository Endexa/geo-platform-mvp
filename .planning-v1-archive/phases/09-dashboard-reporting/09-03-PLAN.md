  <files>

  <action>
Update `frontend/pages/dashboard.vue` (already rewritten by Plan 02) to add audit history support:

1. Add new state ref: `auditHistory` (array, default []), `historyLoading` (bool, default false).

2. After the overview data loads successfully (in the watch on selectedAuditId), also fetch history:
```typescript
historyLoading.value = true
try {
  const historyData = await useApiFetch<{ domain: string, entries: any[], total: number }>(
    '/dashboard/history',
    { params: { domain: overview.value.domain } }
  )
  auditHistory.value = historyData.entries || []
} catch (e) {
  // History is supplementary -- fail silently
  auditHistory.value = []
} finally {
  historyLoading.value = false
}
```

3. Add TrendChart to the dashboard template, AFTER the CompetitorRadar section and BEFORE the Recommendation Progress section:
```html
<!-- Audit History Trend -->
<TrendChart
  v-if="auditHistory.length > 0"
  :history="auditHistory"
/>
```

4. If historyLoading is true, show a skeleton placeholder in place of the TrendChart (a `bg-white rounded-xl shadow-sm border p-6` div with a `h-64 bg-gray-100 rounded animate-pulse` inner div).

NOTE: Plan 02 creates the dashboard.vue rewrite. This plan modifies it to add the history section. Read the file first to understand the current structure, then add the history-related code (state refs, API call in watch, template section) without breaking existing functionality.
