  <action>
    Add `nltk` to `backend/requirements.txt` if not already present (needed for sentence tokenization). Also ensure textstat is listed (it already is).

    Create `backend/app/services/scoring/content_structure_scorer.py`:
    - Import BaseScorer, ScoringCriterionResult from base_scorer
    - Import BeautifulSoup from bs4
    - Import textstat for readability scoring
    - Import nltk (with punkt_tab download guard: `try: nltk.data.find('tokenizers/punkt_tab') except: nltk.download('punkt_tab', quiet=True)`)
    - Import re for pattern matching
    - Import loguru logger

    Class `ContentStructureScorer(BaseScorer)`:

    `async def score_page(self, page_data: dict) -> list[ScoringCriterionResult]`:
    - page_data has: url, html (raw HTML), main_content (extracted text), crawl_data (CrawlResult dict)
    - Parse HTML with BeautifulSoup once, pass soup to criteria methods
    - Call all 13 criteria methods and return collected results

    **CS1: Heading hierarchy quality (GRADIENT)**
    - Method: `def _check_heading_hierarchy(self, soup: BeautifulSoup) -> ScoringCriterionResult`
    - Check: exactly 1 H1, H2s under H1, H3s under H2s (no skipping levels like H1->H3)
    - Scoring: Start at 100, -30 if no H1, -20 if multiple H1s, -15 per skipped level (e.g. H1 directly to H3), -10 if fewer than 2 H2s. Clamp 0-100.
    - Human summary: "Good heading structure: 1 H1, 5 H2s, 8 H3s -- clean hierarchy" or "Issues: No H1 tag found, H3 used without H2 parent"
    - Evidence: {h1_count, h2_count, h3_count, skipped_levels, issues}

    **CS2: Answer-first format detection (GRADIENT)**
    - Method: `def _check_answer_first(self, soup: BeautifulSoup) -> ScoringCriterionResult`
    - For each H2/H3, get the immediately following text block (first paragraph or text node)
    - Check if heading is question-like (ends with "?" or starts with what/how/why/when/where/which/who/can/does/is)
    - Check if first sentence after heading is a direct answer (10-60 words, declarative)
    - Score per heading block: +40 if question heading, +40 if direct answer, +20 if has supporting detail (>1 sentence)
    - Overall score = average of per-heading scores across all H2/H3 blocks. If no headings, score 0.
    - Human summary: "{N} of {M} sections follow answer-first format -- {Good/Needs improvement}"
    - Evidence: {total_sections, answer_first_count, question_headings_count}

    **CS3: Paragraph length (GRADIENT)**
    - Method: `def _check_paragraph_length(self, soup: BeautifulSoup) -> ScoringCriterionResult`
    - Extract all <p> tags with >20 words (skip empty/short decorative paragraphs)
    - For each paragraph, count sentences using nltk.sent_tokenize()
    - Ideal: 2-4 sentences per paragraph. Score each paragraph: 2-4 sentences = 100, 1 sentence = 60, 5-6 sentences = 70, 7+ sentences = 30.
    - Overall = average of paragraph scores. If < 3 meaningful paragraphs, score 30.
    - Human summary: "Average {X} sentences per paragraph -- {ideal for AI extraction / too long / too short}"
    - Evidence: {total_paragraphs, avg_sentences, ideal_count, long_count, short_count}

    **CS4: Data density (GRADIENT)**
    - Method: `def _check_data_density(self, soup: BeautifulSoup) -> ScoringCriterionResult`
    - Count: <table> elements, <ol>/<ul> lists with >2 items, statistics in text (regex: numbers with %, $, x/X multipliers like "2.3x", "4.1x")
    - Scoring: tables = 30 pts (max), lists = 30 pts (max), statistics = 40 pts (max). Scale each: 0 items = 0 pts, 1 item = half pts, 2+ items = full pts.
    - Human summary: "Data density: {N} tables, {M} lists, {P} statistics -- {Rich/Moderate/Low}"
    - Evidence: {table_count, list_count, statistic_count, statistic_examples}

    **CS5: FAQ section presence (GRADIENT)**
    - Method: `def _check_faq_presence(self, soup: BeautifulSoup) -> ScoringCriterionResult`
    - Detection signals: heading containing "FAQ" or "Frequently Asked" (case-insensitive), <details>/<summary> elements, <dl> definition lists with question-like dt elements, consecutive question-style headings (3+ H3s ending with "?")
    - Score: 100 if FAQ section found with 3+ Q&A pairs, 70 if FAQ section found with 1-2 pairs, 40 if question-style headings but no formal FAQ section, 0 if no FAQ signals
    - Human summary: "FAQ section found with {N} questions -- great for AI query matching" or "No FAQ section detected"
    - Evidence: {faq_detected, detection_method, question_count}

    **CS6: Content length (GRADIENT)**
    - Method: `def _check_content_length(self, main_content: str) -> ScoringCriterionResult`
    - Count words in main_content
    - Scoring: <300 words = 20, 300-600 = 40, 600-1200 = 60, 1200-1800 = 100 (optimal), 1800-3000 = 80, 3000-5000 = 60, >5000 = 40
    - Human summary: "{N} words -- {Optimal/Short/Long} for AI extraction"
    - Evidence: {word_count, optimal_range: "1200-1800"}

    **CS7: Readability score (GRADIENT)**
    - Method: `def _check_readability(self, main_content: str) -> ScoringCriterionResult`
    - Use `textstat.flesch_kincaid_grade(main_content)` -- returns grade level
    - Scoring: grade 8-10 = 100 (ideal), 6-8 or 10-12 = 80, 4-6 or 12-14 = 50, <4 or >14 = 20
    - If main_content too short (<100 words), return _not_checked
    - Human summary: "Grade level {X} -- {Clear and accessible / Too simple / Too complex} for AI extraction"
    - Evidence: {flesch_kincaid_grade, flesch_reading_ease: textstat.flesch_reading_ease()}

    **CS8: Citation/reference presence (GRADIENT)**
    - Method: `def _check_citations(self, soup: BeautifulSoup, main_content: str) -> ScoringCriterionResult`
    - Count: outbound links to authoritative domains (check <a> href for .edu, .gov, wikipedia.org, arxiv.org, pubmed, doi.org), text patterns like "[1]", "(Source:)", "according to", "study by", "research shows"
    - Score: 0 citations = 0, 1-2 = 40, 3-5 = 70, 6+ = 100
    - Human summary: "{N} citations/references detected -- {Strong/Some/No} source attribution"
    - Evidence: {citation_count, authoritative_links, text_citations}

    **CS9: Content freshness (GRADIENT)**
    - Method: `def _check_freshness(self, soup: BeautifulSoup, crawl_data: dict) -> ScoringCriterionResult`
    - Look for date signals: <time> elements, meta tags (article:published_time, article:modified_time, datePublished, dateModified), visible date patterns in text (regex for YYYY-MM-DD, Month DD YYYY, DD/MM/YYYY)
    - Calculate days since most recent date found
    - Score: <30 days = 100, 30-90 days = 80, 90-365 days = 50, 1-2 years = 25, >2 years or no date = 10
    - Human summary: "Last updated {date} ({N} days ago) -- {Fresh/Aging/Stale}"
    - Evidence: {dates_found, most_recent_date, days_since_update}

    **CS10: Statistics density (GRADIENT)**
    - Method: `def _check_statistics(self, main_content: str) -> ScoringCriterionResult`
    - Count statistics in text: numbers with % (e.g. "45%", "2.5%"), dollar amounts ("$1.2M"), multipliers ("3.2x", "4x"), specific numbers with units ("1,325 rows", "53 criteria")
    - Regex patterns: `r'\d+\.?\d*%'`, `r'\$[\d,.]+[KMBTkmbt]?'`, `r'\d+\.?\d*[xX]'`, `r'\d{1,3}(?:,\d{3})+\s+\w+'`
    - Per 1000 words: 0 stats = 0, 1-2 = 30, 3-5 = 60, 6-10 = 90, 10+ = 100
    - Human summary: "{N} statistics per 1000 words -- {Rich/Moderate/Low} data signals"
    - Evidence: {stat_count, per_1000_words, examples}

    **CS11: Quotation presence (GRADIENT)**
    - Method: `def _check_quotations(self, soup: BeautifulSoup, main_content: str) -> ScoringCriterionResult`
    - Count: <blockquote> elements, text in quotation marks (regex: `"[^"]{20,}"` or `\u201c[^\u201d]{20,}\u201d`), attribution patterns ("-- John Doe", "says CEO")
    - Score: 0 quotes = 0, 1 = 40, 2-3 = 70, 4+ = 100
    - Human summary: "{N} expert quotes detected -- {Strong/Some/No} authority signals"
    - Evidence: {blockquote_count, inline_quote_count, attributed_count}

    **CS12: Entity density (GRADIENT)**
    - Method: `def _check_entity_density(self, main_content: str) -> ScoringCriterionResult`
    - Use regex-based entity detection (no spaCy to avoid 500MB dependency):
      - Capitalized multi-word phrases (2-4 words starting with capitals, not at sentence start): `r'(?<![.!?]\s)\b[A-Z][a-z]+(?:\s+[A-Z][a-z]+){1,3}\b'`
      - Known entity patterns: URLs, email addresses, @handles
    - Count entities per 100 words of main_content
    - Score: <1 per 100 = 20, 1-2 = 40, 2-4 = 70, 4-6 = 90, 6+ = 100
    - Human summary: "{X} named entities per 100 words -- {High/Moderate/Low} entity density"
    - Evidence: {entity_count, per_100_words, sample_entities}

    **CS13: Sentence length variety (GRADIENT)**
    - Method: `def _check_sentence_variety(self, main_content: str) -> ScoringCriterionResult`
    - Tokenize sentences with nltk.sent_tokenize(). Calculate word counts per sentence.
    - Compute coefficient of variation (std_dev / mean) of sentence lengths
    - Score: CV > 0.5 = 100 (high variety), 0.3-0.5 = 70, 0.15-0.3 = 40, <0.15 = 20 (monotonous)
    - If < 5 sentences, return _not_checked
    - Human summary: "Sentence length variety: {High/Moderate/Low} -- mix of {short} to {long} word sentences"
    - Evidence: {mean_sentence_length, std_dev, cv, min_length, max_length, sentence_count}
