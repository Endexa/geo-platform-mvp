<task type="auto">
  <name>Task 2: Create MentionDetectorService with layered exact + fuzzy detection</name>
  <files>
    backend/app/services/mention_detector.py
  </files>
  <action>
    Create `backend/app/services/mention_detector.py` with class `MentionDetectorService`:

    1. **Constructor**: Accept optional config overrides (fuzzy_threshold, short_name_threshold, context_window_chars). Default to settings values.

    2. **generate_brand_variants(brand_name: str) -> list[str]**: Generate variants from brand name:
       - As-is, lowercase, uppercase forms
       - Without common suffixes (Inc., LLC, Ltd., Co., Corp., Corporation, Group, Holdings)
       - Abbreviation for multi-word names (first letter of each word, if >= 2 letters)
       - Domain-style (no spaces, lowered)
       - Discard the original from the variant list (it's matched separately)

    3. **detect_mentions(response_text: str, brand_name: str, brand_variants: list[str]) -> list[dict]**: Two-pass detection returning list of mention dicts.

       **Pass 1 (Exact regex):** For brand_name + all variants, compile `re.compile(r'\b' + re.escape(name) + r'\b', re.IGNORECASE)`. For brand names shorter than 4 chars, use case-SENSITIVE matching (no re.IGNORECASE) to avoid false positives (e.g., "Go" matching "go"). Use `re.finditer` to get all matches. For each match, call `_extract_context()` and build mention dict with: matched_text, match_type="exact", confidence=100, char_offset, context_quote.

       **Pass 2 (Fuzzy matching -- only if no exact matches found):** Split response_text into sentences using `_split_sentences()`. For each sentence, compute `fuzz.token_set_ratio(brand_name.lower(), sentence.lower())`. If score >= threshold (use short_name_threshold for brands < 4 chars, else fuzzy_threshold), ALSO compute `fuzz.partial_ratio` and require BOTH to exceed threshold. Build mention dict with: matched_text=sentence.strip(), match_type="fuzzy", confidence=min(score, partial), char_offset from sentence position, context_quote=sentence.strip().

       **Deduplication:** After both passes, deduplicate by char_offset range overlap. If a fuzzy match overlaps with an exact match (within 50 chars), keep only the exact match.

    4. **_extract_context(text: str, match_start: int, match_end: int) -> str**: Extract verbatim quote:
       - Start with character window (context_window_chars / 2 before and after match)
       - Expand outward to sentence boundaries (look for .!?\n within 50 chars of window edges)
       - Cap at 500 chars total to prevent capturing entire paragraphs
       - Strip and return

    5. **_split_sentences(text: str) -> list[str]**: Use `re.split(r'(?<=[.!?])\s+', text)` -- simple regex sufficient for AI-generated text (clean punctuation).

    6. **_sentence_offset(text: str, sentence_index: int, sentences: list[str]) -> int**: Compute character offset of a sentence in the original text by summing lengths of prior sentences plus separators. Use `text.find(sentence)` as a simpler approach.

    Use loguru logger for info/warning logging (e.g., warn when brand name is < 4 chars, log number of exact vs fuzzy matches found).
  </action>

  <files>

  <action>
    Create `backend/app/services/scoring_service.py` with class `ScoringService`:

    1. **Constructor**: Accept `db: Session` parameter (SQLAlchemy session, same pattern as CostTrackingService).

    2. **compute_audit_score(audit_id: str, total_queries: int) -> VisibilityScore**: Main entry point. Loads all BrandMention records for the audit (join through EngineResponse -> AuditQuery -> filter by audit_id). Groups mentions by engine. Calls `_compute_per_engine_score()` for each engine. Computes overall score as average of engine scores. Creates and returns a VisibilityScore model instance (do NOT db.add/commit -- caller manages transaction).

       Query pattern: `db.query(BrandMention).join(EngineResponse).join(AuditQuery).filter(AuditQuery.audit_id == audit_id)` to get all mentions for an audit. Also query successful EngineResponse records (where error_message IS NULL) grouped by engine to know total responses per engine.

    3. **_compute_per_engine_score(mentions_by_query: dict[str, list[dict]], total_queries_for_engine: int) -> int**: Compute score for one engine using weighted formula:
       - **mention_rate (40%)**: Percentage of successful responses that contain at least one mention. `(responses_with_mentions / total_queries_for_engine) * 100`.
       - **position_score (30%)**: Average normalized position of first mention in each response. `100 - (first_mention_char_offset / 20)`, clamped to 0-100. Earlier mentions = higher score.
       - **prominence_score (30%)**: Average confidence of best mention per response. Exact matches (100) rank higher than fuzzy matches.
       - Formula: `mention_rate * 0.40 + avg_position * 0.30 + avg_prominence * 0.30`
       - Clamp result to 0-100 and round.

    4. **Filter out error responses**: When querying EngineResponse records, filter `EngineResponse.error_message.is_(None)` before computing. Only score engines that successfully returned responses.

    5. **Compute aggregate fields**: `mention_count` = total number of BrandMention records for the audit. `query_mention_rate` = percentage of (query, engine) pairs that have at least one mention.

    6. **algorithm_version**: Set to `"v1"` for reproducibility tracking.

    Use loguru logger for scoring details (log per-engine scores, overall score, mention count).
