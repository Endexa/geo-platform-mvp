    1. **Migrate security.py to PyJWT + pwdlib**:
       - Replace `from jose import JWTError, jwt` with `import jwt` and `from jwt.exceptions import InvalidTokenError`
       - Replace `pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")` with `from pwdlib import PasswordHash` and `password_hash_ctx = PasswordHash.recommended()`
       - Update `SecurityManager.hash_password()` to use `password_hash_ctx.hash(password)`
       - Update `SecurityManager.verify_password()` to use `password_hash_ctx.verify(plain_password, hashed_password)`
       - Update `SecurityManager.verify_token()`: replace `except JWTError` with `except InvalidTokenError`
       - Replace ALL `datetime.utcnow()` calls with `datetime.now(timezone.utc)` (import `timezone` from `datetime`)
       - Fix `sign_request` (H-8): replace `hmac.new(...)` with `hmac.HMAC(secret.encode(), payload.encode(), hashlib.sha256).hexdigest()`
       - Update `get_current_active_user` to check `if not current_user.is_active: raise HTTPException(status_code=403, detail="Account deactivated")`

    2. **Create backend/app/schemas/__init__.py**: Empty file.

    3. **Create backend/app/schemas/auth.py**: Define Pydantic v2 models:
       - `RegisterRequest(BaseModel)` with `email: EmailStr`, `password: str`, `full_name: str | None = None`. Add `@field_validator("password")` enforcing min 12 chars, requires upper + lower + digit + special character. Use `@classmethod` decorator.
       - `LoginRequest(BaseModel)` with `email: EmailStr`, `password: str`.
       - `TokenResponse(BaseModel)` with `access_token: str`, `refresh_token: str | None = None`, `token_type: str = "bearer"`.
       - `UserResponse(BaseModel)` with `id: str`, `email: str`, `full_name: str | None`, `role: str`. Set `model_config = ConfigDict(from_attributes=True)` (Pydantic v2 style, not inner `Config` class).

    4. **Create backend/app/services/auth_service.py**: Class `AuthService`:
       - `__init__(self, db: Session)` stores the db session.
       - `register(self, email: str, password: str, full_name: str | None) -> Profile`: Check duplicate email (query Profile by email, raise HTTPException 400 if exists). Create Profile with `id=uuid.uuid4()`, `email=email`, `password_hash=SecurityManager.hash_password(password)`, `full_name=full_name`, `is_active=True`. Add, commit, refresh, return.
       - `authenticate(self, email: str, password: str) -> Profile`: Query Profile by email. If not found or `not SecurityManager.verify_password(password, user.password_hash)`, raise HTTPException 401. If `not user.is_active`, raise HTTPException 403. Return user.

    5. **Create backend/app/api/auth.py**: FastAPI router with:
       - `POST /register` accepting `RegisterRequest`, using `AuthService(db).register(...)`, creating access token via `SecurityManager.create_access_token(data={"sub": str(user.id)})`, returning `TokenResponse`.
       - `POST /login` accepting `LoginRequest`, using `AuthService(db).authenticate(...)`, creating access + refresh tokens, returning `TokenResponse`.
       - `GET /me` with `Depends(get_current_active_user)`, returning `UserResponse` from the current user Profile.
       - Do NOT add rate limiting to auth endpoints yet (that uses the existing inbound rate limiter which is a separate concern).
