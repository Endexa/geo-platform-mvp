   ```python

   logger.info("Audit {}: starting dispatch to AI engines", audit_id)
   audit.status = AuditStatus.DISPATCHING.value
   db.commit()

   # Reload queries from DB to get their IDs (needed for FK in engine_responses)
   queries = db.query(AuditQuery).filter(AuditQuery.audit_id == audit_id).all()

   dispatcher = DispatchService(db)
   dispatch_result = dispatcher.dispatch_all_queries(
       audit_id=audit_id,
       queries=queries,
   )
   logger.info(
       "Audit {}: dispatched {} queries, {} responses, {} failures, budget_exceeded={}",
       audit_id,
       dispatch_result.total_queries,
       dispatch_result.total_responses,
       dispatch_result.total_failures,
       dispatch_result.budget_exceeded,
   )
   ```

   ```python
   # Mark as completed

   ```

   In the `get_audit_detail` endpoint (GET /{audit_id}):
   - The existing code returns `AuditDetailResponse`. Since AuditQueryResponse now includes `engine_responses` and the AuditQuery model has the `engine_responses` relationship, SQLAlchemy will automatically load engine_responses when serializing queries via `from_attributes=True`.

     ```python

     audit = (
         db.query(Audit)
         .options(
             joinedload(Audit.queries).joinedload(AuditQuery.engine_responses)
         )
         .filter(Audit.id == audit_id)
         .first()
     )
     ```
   - Add dispatch_summary computation after loading the audit:
     ```python
     # Compute dispatch summary if audit has engine responses
     dispatch_summary = None
     if audit.status in (AuditStatus.COMPLETED.value, AuditStatus.DISPATCHING.value):
         all_responses = []
         for q in audit.queries:
             all_responses.extend(q.engine_responses)
         if all_responses:
             engines_used = list(set(r.engine for r in all_responses))
             failures = sum(1 for r in all_responses if r.error_message is not None)
             dispatch_summary = {
                 "total_queries": len(audit.queries),
                 "total_responses": len(all_responses) - failures,
                 "total_failures": failures,
                 "engines_used": sorted(engines_used),
             }
     ```
