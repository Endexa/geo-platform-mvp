    **1. Create `frontend/components/CompetitorLeaderboard.vue`:**

    Displays all discovered entities ranked by share-of-voice.

    **Props:**
    - `competitors: Array` (CompetitorLeaderboardEntry objects from API)
    - `userBrandName: string`

    **Template:**
    - Table with columns: Rank (#), Brand Name, Share of Voice (%), Mentions, Engines, Status
    - Each row:
      - Rank number (1-indexed)
      - Brand name with entity_type badge (ORG/PRODUCT) -- user's brand highlighted with distinct background (e.g., `bg-blue-50`)
      - Share of voice as a percentage with a small inline bar chart (Tailwind width based on percentage relative to max SOV)
      - Total mention_count
      - Engine breakdown: small colored dots/badges for each engine that mentioned the entity (e.g., "GPT" "Claude" "Pplx" "Gemini") with count tooltips using `title` attribute
      - Status column: "Scored" badge (green) if is_crawled and competitor_audit_id exists, "Pending" badge (gray) if resolved_url exists but not yet crawled, "No URL" badge (red) if resolved_url is null
    - User's own brand row uses `is_user_brand` flag for styling
    - Table is scrollable on mobile (overflow-x-auto wrapper)
    - Empty state: "No competitors discovered yet. Run an audit to discover competitors." message

    **Styling:** Follow data-dense dashboard patterns:
    - Table: `class="w-full"` with Tailwind table classes
    - SOV bar: div with `bg-blue-500` and dynamic width `style="width: ${sovPercentRelative}%"`
    - Engine badges: small rounded pills with engine-specific colors (OpenAI=green, Anthropic=purple, Perplexity=blue, Gemini=amber)

    **2. Create `frontend/components/CompetitorComparison.vue`:**

    Side-by-side score comparison between user's site and crawled competitors.

    **Props:**
    - `userScores: Object` (user's optimization_score and per-category averages from audit detail)
    - `competitorAudits: Array` (CompetitorAuditSummary objects from API)

    **Template:**
    - If no competitor audits with status="completed", show "No competitors scored yet" message with hint to trigger crawl
    - Comparison table with columns: Category, Your Score, then one column per crawled competitor (competitor_name as header)
    - Rows for each category:
      - Crawlability (crawlability_avg)
      - Content Structure (content_structure_avg)
      - Structured Data (structured_data_avg)
      - Authority (authority_avg)
      - Overall Optimization Score (optimization_score) -- bottom row, bold
    - Each cell shows the score (0-100) with color coding:
      - Green (>=70), Amber (40-69), Red (<40) -- same getScoreColor pattern used in AuditResults
      - If user score > competitor score: small up arrow (positive indicator)
      - If user score < competitor score: small down arrow (negative indicator)
    - Below the table: a "Score Gaps" summary listing the categories where the user is behind the top competitor, sorted by gap size descending. Example: "Structured Data: You 42 vs Stripe 78 (-36 pts)"

    **Styling:**
    - Card wrapper with `class="card"` pattern
    - Responsive: on mobile, table scrolls horizontally
    - Color coding uses existing `text-success-600`, `text-warning-600`, `text-danger-600` classes (or Tailwind green/amber/red equivalents used in the project)

    **3. Create `frontend/components/SourceCitations.vue`:**

    Displays source URLs that AI engines referenced in their responses.

    **Props:**
    - `engineResponses: Array` (engine response objects with citations field from audit detail)

    **Template:**
    - Section header: "Source Citations" with count of total unique URLs
    - Group citations by engine:
      - Engine name header (e.g., "Perplexity" with engine icon/badge)
      - List of URLs as clickable links (target="_blank", rel="noopener noreferrer")
      - Each URL shows the domain extracted from the full URL for readability, with full URL as tooltip
      - If citations is null or empty for an engine, show "No source citations" message
    - Cross-engine summary: unique domains mentioned across all engines, sorted by frequency
    - Total citation count badge

    **Styling:**
    - Compact list layout fitting within audit detail or competitor section
    - Links use `text-blue-600 hover:text-blue-800 underline` styling
    - Engine grouping uses Disclosure/accordion pattern (collapsed by default, expand to see URLs) -- or simple sections if engine count is small (4 engines)
  </action>

    **1. Create `frontend/pages/competitors.vue`:**

    Full-page competitors view accessible from sidebar navigation.

    **Route:** `/competitors` (auto-routed by Nuxt 3 file-based routing)

    **Template structure:**
    ```
    <NuxtLayout name="dashboard">
      <div class="space-y-6">
        <header with title "Competitor Discovery" and audit selector>
        <CompetitorLeaderboard :competitors :userBrandName />
        <CompetitorComparison :userScores :competitorAudits />
        <section for "Trigger Competitor Crawl" button if uncrawled competitors exist>
      </div>
    </NuxtLayout>
    ```

    **Data loading:**
    - On mount, check for audit_id in route query params (`?audit_id=xxx`). If not present, fetch most recent completed audit from `/api/v1/audit/` and use its ID.
    - Fetch leaderboard data from `GET /api/v1/competitors/{audit_id}/leaderboard` using useApiFetch
    - Fetch audit detail from `GET /api/v1/audit/{audit_id}` to get user's scores (optimization_score and per-category data from page_scores)
    - Extract user's per-category averages from the audit optimization_score data

    **Competitor crawl trigger:**
    - If there are discovered competitors with resolved URLs that are not yet crawled, show a "Score Competitors" button
    - On click, POST to `/api/v1/competitors/{audit_id}/crawl`
    - Show loading state during crawl (spinner + "Scoring competitor sites... This may take 30-60 seconds")
    - On completion, refresh leaderboard and comparison data

    **Error handling:**
    - If no audit exists, show "Run an audit first to discover competitors" message with link to /audit
    - If leaderboard is empty, show "No competitors found in AI responses" message
    - API errors show user-friendly messages (same pattern as audit.vue)

    - The audit detail API response should already include citations on engine_responses (from Plan 01 dispatch modifications). If the field is present, pass it to SourceCitations.
