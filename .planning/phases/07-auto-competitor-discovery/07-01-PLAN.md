    **1. Create `backend/app/services/entity_extractor.py`** implementing EntityExtractorService:

    ```python
    class EntityExtractorService:
        """Extracts brand/entity names and source citations from AI responses."""
    ```

    **Methods:**

    **`__init__(self)`**: Load spaCy model lazily (class-level `_nlp` cache):
    ```python
    _nlp = None
    @classmethod
    def _get_nlp(cls):
        if cls._nlp is None:
            import spacy
            cls._nlp = spacy.load("en_core_web_sm")
        return cls._nlp
    ```

    **`extract_entities_from_response(self, response_text: str) -> list[dict]`**:
    - Run spaCy NER on the FULL response_text (not fragments -- see Research pitfall 1)
    - Keep only ORG and PRODUCT entity types
    - Return list of `{text, label, start_char, end_char}`
    - Post-filter: skip entities shorter than 2 chars

    **`extract_citations(self, response_text: str, citations_meta: list[str] | None = None) -> list[str]`**:
    - If citations_meta is provided (Perplexity), add those URLs
    - Regex extract URLs from response text: `r'https?://[^\s\)\]\},\"\']+`
    - Markdown link extraction: `r'\[([^\]]+)\]\((https?://[^\)]+)\)'`
    - Return sorted deduplicated list of URLs

    **`extract_all_entities_for_audit(self, db: Session, audit_id: str, user_brand_name: str) -> list[dict]`**:
    - Query all successful EngineResponse records for the audit (join through AuditQuery)
    - For each response: extract entities + extract citations
    - Track per-entity: which engines mentioned it, which queries, total count
    - Build raw entity list: `{text, label, engine, query_id, citations: [...]}`

    **`deduplicate_entities(self, raw_entities: list[dict], threshold: int = 85) -> list[dict]`**:
    - Use rapidfuzz token_set_ratio for fuzzy matching
    - Strip corporate suffixes ("Inc.", "Inc", "LLC", "Ltd.", "Ltd", "Co.", "Corp.", "Corp") before comparison
    - Group entities with score >= threshold
    - Keep the most frequent variant as canonical_name
    - Return: `[{canonical_name, entity_type, mention_count, engines_mentioned_in: {engine: count}, queries_mentioned_in: [query_ids]}]`
    - IMPORTANT: Sort by mention_count descending

    **`compute_share_of_voice(self, ranked_entities: list[dict], user_brand_name: str) -> list[dict]`**:
    - SOV = (entity_mentions / total_mentions_across_all_entities) * 100
    - Mark `is_user_brand = True` if rapidfuzz.fuzz.ratio(canonical_name.lower(), user_brand_name.lower()) > 90
    - Return sorted by mention_count descending

    **`discover_competitors_for_audit(self, db: Session, audit_id: str, user_brand_name: str) -> list[DiscoveredCompetitor]`**:
    - Orchestration method: calls extract_all_entities_for_audit -> deduplicate -> compute_share_of_voice
    - For each unique entity, create a DiscoveredCompetitor record in DB
    - Set is_user_brand flag based on SOV computation
    - db.flush() after adding all records
    - Return list of DiscoveredCompetitor objects

    **Blocklist for generic terms** (class constant):
    ```python
    GENERIC_BLOCKLIST = {"the", "this", "that", "these", "those", "it", "its",
                         "their", "our", "your", "my", "service", "platform",
                         "tool", "product", "company", "website", "app",
                         "application", "software", "solution", "system"}
    ```
    Filter out entities whose lowercase canonical_name is in GENERIC_BLOCKLIST.
    Also filter entities that appear in only 1 response (Research pitfall 2: require at least 2 appearances).
