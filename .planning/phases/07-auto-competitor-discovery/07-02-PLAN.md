    **2. Create `backend/app/services/competitor_service.py`** implementing CompetitorService:

    ```python
    class CompetitorService:
        """Orchestrates competitor URL resolution, crawling, and scoring."""
    ```

    **`__init__(self, db: Session)`**: Store db reference.

    **`async def resolve_competitor_url(self, entity_name: str, citation_urls: list[str]) -> str | None`**:
    Layered URL resolution (from Research Pattern 4):
    1. Check citation_urls for domain matching the entity name (rapidfuzz.fuzz.partial_ratio > 70)
    2. Domain heuristic: try `https://www.{clean_name}.com`, HTTP HEAD with 5s timeout via httpx.AsyncClient(follow_redirects=True). Accept if status < 400.
    3. Google Knowledge Graph API (if settings.GOOGLE_API_KEY is set): GET `https://kgsearch.googleapis.com/v1/entities:search?query={entity_name}&key={key}&limit=1&types=Organization`, extract `result.detailedDescription.url` or `result.url` from response.
    4. Return None if all fail.
    Clean name: lowercase, strip spaces, commas, periods, corporate suffixes (Inc, LLC, Ltd, Corp, Co).

    **`async def crawl_and_score_competitor(self, parent_audit_id: str, competitor: DiscoveredCompetitor) -> CompetitorAudit | None`**:
    1. If competitor.resolved_url is None, try resolve_competitor_url first. If still None, return None.
    2. Create CompetitorAudit record (status="crawling"), db.flush()
    3. Update competitor.competitor_audit_id and competitor.is_crawled = True
    4. Use CrawlerService to crawl competitor URL (single page crawl, NOT crawl_multiple -- simpler for competitors)
    5. Store crawl_data on CompetitorAudit
    6. Update status to "scoring"
    7. Import and instantiate ScoringOrchestrator. Register all 4 scorers (same pattern as audit_tasks.py -- try/except ImportError for each).
    8. Call ScoringOrchestrator methods to score the crawled pages, but use COMPETITOR_CRAWL_CAP from settings (default 5 pages, not 25).
    9. Extract per-category averages from the scoring results and store on CompetitorAudit (crawlability_avg, content_structure_avg, structured_data_avg, authority_avg, optimization_score, pages_scored).
    10. Update status to "completed". Return CompetitorAudit.
    11. Wrap entire method in try/except: on failure, set status="failed" and log error.

    **Important design note:** The ScoringOrchestrator.score_audit() method creates PageScore and CriterionResult records tied to an audit_id. For competitors, we need to store scores differently since CompetitorAudit is NOT in the audits table. Instead of calling score_audit(), call the individual scorers manually:
    - Use CrawlerService.crawl_multiple() to get pages (with COMPETITOR_CRAWL_CAP limit)
    - For each page, run each registered scorer's score_page() method
    - Collect ScoringCriterionResult dataclass instances
    - Compute per-category averages using the same compute_category_score logic from BaseScorer
    - Store averages directly on CompetitorAudit (no PageScore/CriterionResult DB records for competitors -- keeps data model clean per Research note)

    **`async def crawl_top_competitors(self, audit_id: str, max_competitors: int | None = None) -> list[CompetitorAudit]`**:
    1. Query DiscoveredCompetitor records for audit_id, ordered by mention_count DESC, where is_user_brand=False and is_crawled=False
    2. Limit to max_competitors (default from settings.COMPETITOR_MAX_COUNT = 5)
    3. For each competitor, gather citation URLs from EngineResponse.citations for that audit
    4. Call resolve_competitor_url, update resolved_url on DiscoveredCompetitor record
    5. For resolved competitors, call crawl_and_score_competitor sequentially (not parallel -- avoid rate limiting)
    6. db.commit() after all competitors processed
    7. Return list of CompetitorAudit records

    **`def get_leaderboard(self, audit_id: str) -> dict`**:
    1. Query all DiscoveredCompetitor records for audit_id, ordered by mention_count DESC
    2. Query CompetitorAudit records for audit_id
    3. Get the user's brand name from the Audit.crawl_data (same extract_brand_name pattern as query_generator)
    4. Return dict with audit_id, user_brand_name, total_entities count, competitors list, competitor_audits list

    **Endpoints:**

    **`GET /api/v1/competitors/{audit_id}/leaderboard`** (auth required):
    - Depends: `db: Session = Depends(get_db)`, `current_user = Depends(get_current_active_user)`
    - Verify audit exists and belongs to current_user (same pattern as audit.py)
    - Call `CompetitorService(db).get_leaderboard(audit_id)`
    - Return CompetitorLeaderboardResponse
    - If no discovered_competitors exist for audit, return response with empty competitors list and total_entities=0

    **`POST /api/v1/competitors/{audit_id}/crawl`** (auth required):
    - Depends: `db: Session = Depends(get_db)`, `current_user = Depends(get_current_active_user)`
    - Verify audit exists and belongs to current_user
    - Optional query param: `max_competitors: int = None` (overrides COMPETITOR_MAX_COUNT)
    - Call `await CompetitorService(db).crawl_top_competitors(audit_id, max_competitors)`
    - Return `{"status": "completed", "competitors_crawled": len(results), "competitor_audits": [audit summaries]}`
    - Note: This is a synchronous endpoint (not Celery task) since competitor crawling is expected to take 30-60s for 3-5 competitors. If this proves too slow, can be moved to Celery later.

    **`GET /api/v1/competitors/{audit_id}/competitor/{competitor_audit_id}`** (auth required):
    - Depends: `db: Session = Depends(get_db)`, `current_user = Depends(get_current_active_user)`
    - Query CompetitorAudit by id, verify parent_audit belongs to current_user
    - Return CompetitorAuditSummary with full details

    **2. Modify `backend/app/tasks/audit_tasks.py`**:

    In the DISCOVERING_COMPETITORS stage (added by Plan 01), AFTER entity extraction, add competitor crawling:

    ```python
    # After entity extraction (already in place from Plan 01)
    # Now resolve URLs and crawl top competitors
    import asyncio
    from app.services.competitor_service import CompetitorService

    competitor_svc = CompetitorService(db)
    loop = asyncio.new_event_loop()
    try:
        competitor_audits = loop.run_until_complete(
            competitor_svc.crawl_top_competitors(audit_id)
        )
        logger.info(
            "Audit {}: crawled {} competitor sites",
            audit_id, len(competitor_audits)
        )
    except Exception as e:
        logger.error("Audit {}: competitor crawling failed: {}", audit_id, str(e))
        # Non-fatal: competitor crawl failure should not fail the audit
    finally:
        loop.close()
    ```

    Important: Competitor crawling is NON-FATAL. If it fails, the audit still completes. Wrap in try/except and log the error.
