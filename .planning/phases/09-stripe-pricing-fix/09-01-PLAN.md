Endpoint to add (insert as the first GET endpoint in the file, after the existing `@router.post("/create-checkout", ...)` block or anywhere logical in the endpoints section — add after the `get_session_status` endpoint):
```python
@router.get("/subscription-status", response_model=SubscriptionStatusResponse)
async def get_subscription_status(
    current_user: Profile = Depends(get_current_active_user),
    db: Session = Depends(get_db),
):
    """Return the current user's subscription tier for frontend rehydration on page load.

    Authenticated. No rate limiting needed (read-only, lightweight DB query).
    Returns tier='pro' if active or trialing subscription exists, else tier='free'.
    """
    sub = (
        db.query(Subscription)
        .filter(
            Subscription.user_id == current_user.id,
            Subscription.status.in_(["active", "trialing"]),
        )
        .first()
    )
    return SubscriptionStatusResponse(
        tier="pro" if sub else "free",
        status=sub.status if sub else None,
    )
```

Important: The existing `Subscription` model is already imported via `from app.models.subscription import Subscription, WebhookEvent`. The `Optional` type is already imported. `get_db` and `get_current_active_user` are already imported. No new imports needed.
