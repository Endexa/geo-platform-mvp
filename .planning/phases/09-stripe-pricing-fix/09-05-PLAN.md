Same 3-tier layout as pricing.vue (from plan 02):
- Free: border border-slate-200, $0/mo, 3 included features, 2 excluded, CTA = NuxtLink to="/audit" (border button)
- Pro: border-2 border-primary-800, shadow-lg, "Most Popular" badge, $29/mo, 8 included features, amber CTA button `@click="handleSubscribe"` with loading/error state
- Enterprise: border border-slate-200, "Custom pricing", 5 included features, CTA = `<a href="mailto:hello@endexa.com">` border button

handleSubscribe reads `config.public.stripePriceProMonthly` — same pattern as pricing.vue.

Script:
```typescript
const config = useRuntimeConfig()
const { redirectToCheckout } = useStripe()
const loading = ref(false)
const error = ref('')

const handleSubscribe = async () => {
  const priceId = config.public.stripePriceProMonthly
  if (!priceId) {
    error.value = 'Contact support@endexa.com to subscribe'
    return
  }
  loading.value = true
  error.value = ''
  try {
    await redirectToCheckout(priceId)
  } catch (err: any) {
    error.value = err?.data?.detail || 'Failed to start checkout. Please try again.'
    loading.value = false
  }
}
```

Add a note below the grid: `<p class="text-center text-sm text-slate-500 mt-8">All plans include a 14-day refund policy. No questions asked.</p>`
