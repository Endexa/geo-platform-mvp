1. Create `frontend/composables/useCodeAnalysis.ts`:
   Export function `useCodeAnalysis(auditId: Ref<string>)` returning:
   `{ isDownloading, isUploading, isPolling, codeAnalysis, recommendations, error, downloadPrompts, uploadOutput, loadAnalysis, loadRecommendations }`

   - `isDownloading`: `ref(false)` — prompt download in progress
   - `isUploading`: `ref(false)` — upload request in progress
   - `isPolling`: `ref(false)` — status polling active
   - `codeAnalysis`: `ref<CodeAnalysisResponse | null>(null)` — latest analysis status/data
   - `recommendations`: `ref<CodeRecommendationResponse[]>([])` — code recommendations
   - `error`: `ref<string | null>(null)` — error message

   TypeScript interfaces (inline in the file):
   ```typescript
   interface GeneratedPrompt { category: string; title: string; prompt_text: string; priority: string; target_count: number }
   interface PromptsResponse { audit_id: string; domain: string; generated_at: string; prompts: GeneratedPrompt[]; markdown_bundle: string }
   interface CodeAnalysisResponse { id: string; audit_id: string; status: string; detected_framework: string | null; error_message: string | null; created_at: string; completed_at: string | null }
   interface CodeRecommendationResponse { id: string; code_analysis_id: string; criterion_id: string | null; category: string; severity: string; finding: string; file_path: string | null; suggestion: string; code_snippet: string | null; evidence: string | null; status: string; created_at: string }
   ```

   `async downloadPrompts()`:
   - Set isDownloading=true, clear error
   - Call `useApiFetch<PromptsResponse>(`/code-analysis/${auditId.value}/prompts`, { method: 'POST' })`
   - On success: trigger browser download of markdown_bundle as a .md file:
     ```typescript
     const blob = new Blob([data.markdown_bundle], { type: 'text/markdown' })
     const url = URL.createObjectURL(blob)
     const a = document.createElement('a')
     a.href = url
     a.download = `endexa-analysis-prompts-${data.domain}.md`
     a.click()
     URL.revokeObjectURL(url)
     ```
   - On error: set error.value to the error message
   - Always: set isDownloading=false

   `async uploadOutput(text: string, categoriesUsed: string[])`:
   - Guard: return if isUploading or text.trim().length < 10
   - Set isUploading=true, clear error
   - Call `useApiFetch<{id: string; status: string}>(`/code-analysis/${auditId.value}/upload`, { method: 'POST', body: { output: text, categories_used: categoriesUsed } })`
   - On success: set codeAnalysis.value to response data (id + status), start polling via startPolling()
   - On error: set error.value
   - Always: set isUploading=false

   `async loadAnalysis()`:
   - Call `useApiFetch<CodeAnalysisResponse>(`/code-analysis/${auditId.value}`)` (GET)
   - On success: set codeAnalysis.value. If status "completed": call loadRecommendations(). If status "failed": set error.value to code_analysis.error_message.
   - Silently ignore 404 (no analysis yet — that's normal)

   `async loadRecommendations()`:
   - Call `useApiFetch<CodeRecommendationResponse[]>(`/code-analysis/${auditId.value}/recommendations`)` (GET)
   - On success: set recommendations.value

   `startPolling()` / `stopPolling()` (internal):
   - Use `useIntervalFn` from @vueuse/core (already in project per chat composable pattern)
   - 3-second interval, immediate: false
   - On each tick: call loadAnalysis()
   - Stop when status is "completed" or "failed"
   - Set isPolling accordingly

   On `auditId` watcher change: call loadAnalysis() to check if existing analysis exists.
