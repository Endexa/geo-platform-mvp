Create `backend/app/schemas/dashboard.py` with Pydantic v2 response schemas:
- `TopIssueSchema`: id, page_url (nullable), criterion_id, criterion_name, category, priority, impact_label, summary, gap_score (from AuditRecommendation)
- `CompetitivePositionSchema`: user_scores dict (visibility, optimization, crawlability, content_structure, structured_data, authority), competitors list (each with name, share_of_voice, scores dict with same keys). Competitor visibility comes from their share_of_voice. Competitor optimization/category scores come from CompetitorAudit fields.
- `RecommendationProgressSchema`: done int, dismissed int, open int, total int
- `AuditHistoryEntry`: audit_id str, date str, visibility_score int, optimization_score int, combined_score int, mention_count int
- `AuditHistoryResponse`: domain str, entries list[AuditHistoryEntry], total int
- `DashboardOverviewResponse`: audit_id str, domain str, url str, completed_at str | None, combined_geo_score int, visibility_score int, optimization_score int, per_engine_scores dict[str, int], mention_count int, query_mention_rate float, top_issues list[TopIssueSchema], competitive_position CompetitivePositionSchema, recommendation_progress RecommendationProgressSchema
All with `model_config = ConfigDict(from_attributes=True)`.

Create `backend/app/services/dashboard_service.py` with class `DashboardService`:
- `__init__(self, db: Session)` stores db.
- `get_overview(self, audit_id: str, user_id: str) -> dict`: Query Audit (verify user_id match, raise ValueError if not found/not owned). Query VisibilityScore for audit_id. Query top 5 AuditRecommendation with priority="high" and status="open", ordered by gap_score desc. Query top 5 DiscoveredCompetitor (is_user_brand=False) ordered by share_of_voice desc. Query CompetitorAudit with parent_audit_id and status="completed". Query PageScore for audit_id to compute user's category averages (crawlability_score, content_structure_score, structured_data_score, authority_score -- average across all scored pages). Compute combined_geo_score = round(visibility * 0.5 + optimization * 0.5). Count recommendation progress (done/dismissed/open/total). Return dict matching DashboardOverviewResponse fields.
- `get_audit_history(self, domain: str, user_id: str) -> dict`: Query all Audits with matching domain AND user_id AND status="completed", ordered by created_at asc. For each, join VisibilityScore. Return list of AuditHistoryEntry dicts + domain + total.
- `_gather_full_report_data(self, audit_id: str, user_id: str) -> dict`: Comprehensive data collection for export. Includes everything from get_overview PLUS all recommendations (not just top 5), all competitors, all page scores with category breakdowns, all engine responses with mention counts, sentiment data. Returns a flat dict for template rendering.
- `export_pdf(self, audit_id: str, user_id: str) -> bytes`: Calls _gather_full_report_data, renders Jinja2 template `audit_report.html` using Environment(loader=FileSystemLoader("app/templates")), returns HTML(string=html_content).write_pdf(). Import from weasyprint and jinja2.
- `export_csv(self, audit_id: str, user_id: str) -> str`: Calls _gather_full_report_data, uses csv.writer with io.StringIO. Writes sections: Header (domain, date), Scores (combined/visibility/optimization), Per-Engine Breakdown, Category Scores (crawlability/content/schema/authority with user avg), Recommendations (priority, category, criterion_name, summary, gap_score, impact_label, status), Competitors (name, share_of_voice, optimization_score, url). Returns output.getvalue().

- Design system colors: Primary #1E40AF, Background #F8FAFC, Text #1E3A8A. Font: sans-serif (system font in PDF).
- Use CSS only (no JS) -- WeasyPrint renders static HTML+CSS.
