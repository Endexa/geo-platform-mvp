1. `definePageMeta({ layout: 'dashboard' })`.
2. State refs: `loading` (bool), `overview` (null | dashboard overview data), `auditList` (array of {id, domain, url, completed_at} for audit selector), `selectedAuditId` (string | null), `error` (string | null).
3. On mount: Fetch user's completed audits via `useApiFetch('/audit', { params: { status: 'completed' } })`. This returns the list of audits. If the response is an array (check existing audit API), extract completed ones. Set the most recent as selectedAuditId. If no completed audits, show empty state.
4. Watch selectedAuditId: When it changes, fetch `useApiFetch(`/dashboard/overview/${selectedAuditId}`)`. Store in overview ref.
5. Computed properties: `perEngineList` -- transform overview.per_engine_scores into array of {engine, score} for display. `topIssuesList` -- overview.top_issues. `competitorRadarData` -- extract userScores from overview.competitive_position.user_scores and competitors from overview.competitive_position.competitors.
