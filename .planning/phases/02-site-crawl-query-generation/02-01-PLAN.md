**CrawlerService:**

2. Create `backend/app/services/crawler_service.py`:

   - Import: `httpx`, `BeautifulSoup` (from bs4), `extruct`, `urlparse` (from urllib.parse), `RobotFileParser` (from urllib.robotparser), `w3lib.html.get_base_url`, `re`, `collections.Counter`, and schemas from `app.schemas.crawl`

   - Define constant `AI_BOTS` dict mapping user-agent strings to field names:
     ```python
     AI_BOTS = {
         "GPTBot": "gptbot",
         "ChatGPT-User": "chatgpt_user",
         "ClaudeBot": "claudebot",
         "Claude-SearchBot": "claude_searchbot",
         "PerplexityBot": "perplexitybot",
         "Google-Extended": "google_extended",
         "Applebot-Extended": "applebot_extended",
         "CCBot": "ccbot",
     }
     ```

   - Define `MAX_CONTENT_WORDS = 2000` constant for truncation.

   - Create `class CrawlerService`:

     a. `async def crawl(self, url: str) -> CrawlResult`:
        - Fetch URL using `httpx.AsyncClient(timeout=15.0, follow_redirects=True, max_redirects=5)` with `User-Agent: GEOBot/1.0 (+https://geo-platform.com/bot)`
        - Call `response.raise_for_status()`
        - Parse HTML with `BeautifulSoup(response.text, "lxml")`
        - Extract domain from URL using `urlparse`
        - Call helper methods to extract each signal type
        - Return `CrawlResult` with all extracted data

     b. `def _extract_title(self, soup: BeautifulSoup) -> str`:
        - Return `soup.title.get_text(strip=True)` if title tag exists, else `""`

     c. `def _extract_meta_description(self, soup: BeautifulSoup) -> str`:
        - Find `<meta name="description">` and return its `content` attribute, else `""`

     d. `def _extract_headings(self, soup: BeautifulSoup) -> dict[str, list[str]]`:
        - Extract all h1, h2, h3 headings as `{"h1": [...], "h2": [...], "h3": [...]}`
        - Limit to 20 headings per level to avoid bloat

     e. `def _extract_main_content(self, soup: BeautifulSoup) -> str`:
        - Follow existing HTMLAnalyzer pattern: Try `<main>` first, then `<article>`, then largest `<div>` by text length
        - Strip script/style/nav/header/footer tags before extraction
        - Use `element.get_text(separator=" ", strip=True)`
        - Truncate to `MAX_CONTENT_WORDS` words
        - If no content found, fall back to body text

     f. `def _extract_structured_data(self, html: str, url: str) -> dict`:
        - Use `base_url = get_base_url(html, url)`
        - Call `extruct.extract(html, base_url=base_url, syntaxes=["json-ld", "opengraph", "microdata"], uniform=True)`
        - Return dict with keys `json_ld`, `opengraph`, `microdata`
        - Wrap in try/except -- return empty dicts on failure (extruct can fail on malformed HTML)

     g. `def _check_ai_bot_access(self, base_url: str, page_url: str) -> AIBotAccess`:
        - Construct robots_url as `{base_url}/robots.txt`
        - Fetch robots.txt using `httpx.Client` (sync, simple) with 5-second timeout
        - Parse with `RobotFileParser` -- call `rp.parse(response.text.splitlines())`
        - For each bot in `AI_BOTS`, call `rp.can_fetch(user_agent, page_url)`
        - Wrap ALL parsing in try/except -- on any error, return `AIBotAccess()` (all None = no directive found)
        - Important: Do NOT use `rp.read()` (it does its own HTTP fetch with no timeout control). Instead, fetch robots.txt manually with httpx then use `rp.parse()`.

     h. `def _extract_keywords(self, text: str, top_n: int = 20) -> list[str]`:
        - Simple keyword extraction: lowercase, split on whitespace, filter stopwords (hardcoded common English stopwords set), filter words < 3 chars
        - Use `collections.Counter` to count frequencies
        - Return top_n most common words

     i. `def _detect_industry_signals(self, schema_org: list[dict], keywords: list[str]) -> list[str]`:
        - Check schema.org types for industry indicators: `LocalBusiness`, `Restaurant`, `MedicalBusiness`, `LegalService`, `FinancialService`, `RealEstateAgent`, `SoftwareApplication`, `Store`, etc.
        - Map schema types to industry strings: "restaurant", "healthcare", "legal", "finance", "real-estate", "software", "retail"
        - Also check top keywords against industry keyword lists (simple heuristic)
        - Return list of detected industry strings

     j. `def _extract_authority_markers(self, soup: BeautifulSoup) -> dict`:
        - Check for author info: `<meta name="author">`, schema Person
        - Check for about page link: `<a href="*/about*">`
        - Check for contact info: `<a href="*/contact*">`, `mailto:` links, phone patterns
        - Check for trust signals: `<a>` containing "privacy", "terms", "certifications"
        - Return dict like: `{"has_author": bool, "has_about_link": bool, "has_contact": bool, "has_privacy_policy": bool, "has_terms": bool}`
