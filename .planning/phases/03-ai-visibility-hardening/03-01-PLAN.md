<objective>
Enhance the backend visibility scoring pipeline to produce statistically transparent per-engine breakdowns with confidence indicators, skipped-engine reporting, and weighted scoring.

Purpose: Users currently see a single visibility score per engine with no context about how many queries produced it, whether they can trust it, or which engines were skipped. This plan makes the scoring transparent and trustworthy (VIS-01, VIS-02, VIS-03, VIS-04).

Output: Enhanced VisibilityScore model, Alembic migration, enriched ScoringService, enhanced API schemas with backward compatibility.
</objective>

    Changes to `compute_audit_score()`:
    1. After computing per-engine scores (existing loop), build an enriched `per_engine_breakdown` dict for each active engine containing:
       - `score` (int): existing per-engine score from `_compute_per_engine_score()`
       - `queries_sent` (int): `len(engine_responses)` for this engine
       - `queries_with_mentions` (int): number of responses with at least one mention
       - `mention_rate` (float): `round(queries_with_mentions / queries_sent * 100, 1)` (0 if queries_sent=0)
       - `total_mentions` (int): total mention count for this engine
       - `avg_confidence` (int): `round(mean(m.confidence for m in engine_mentions))` (0 if no mentions)
       - `confidence_level` (str): result of `_compute_confidence_level(queries_sent)`
       - `skipped` (bool): `False` for active engines

    2. After processing active engines, iterate over ALL engines from `ENGINE_CONFIG` (import from `dispatch_service`). For any engine NOT in the per_engine_breakdown, add a skipped entry:
       ```python
       {
           "score": 0,
           "queries_sent": 0,
           "queries_with_mentions": 0,
           "mention_rate": 0,
           "total_mentions": 0,
           "avg_confidence": 0,
           "confidence_level": "not_measured",
           "skipped": True,
           "skip_reason": "No API key configured"
       }
       ```

    3. Change overall score from equal-weight average to weighted-by-queries-sent:
       ```python
       total_weighted_score = sum(
           e["score"] * e["queries_sent"]
           for e in per_engine_breakdown.values()
           if not e["skipped"] and e["queries_sent"] > 0
       )
       total_weight = sum(
           e["queries_sent"]
           for e in per_engine_breakdown.values()
           if not e["skipped"] and e["queries_sent"] > 0
       )
       overall_score = round(total_weighted_score / total_weight) if total_weight > 0 else 0
       ```

    4. Compute overall confidence level based on average queries per active engine:
       ```python
       active_engines = [e for e in per_engine_breakdown.values() if not e["skipped"]]
       avg_queries_per_engine = sum(e["queries_sent"] for e in active_engines) // max(len(active_engines), 1)
       overall_confidence = self._compute_confidence_level(avg_queries_per_engine)
       ```

    5. Return VisibilityScore with enriched data:
       ```python
       return VisibilityScore(
           id=uuid.uuid4(),
           audit_id=audit_id,
           overall_score=overall_score,
           per_engine_scores=per_engine_breakdown,  # enriched JSONB
           mention_count=len(mentions),
           query_mention_rate=query_mention_rate,
           algorithm_version="v2",
           confidence_level=overall_confidence,
           engines_queried=len(active_engines),
           engines_skipped=len(per_engine_breakdown) - len(active_engines),
       )
       ```

    6. Bump `ALGORITHM_VERSION` class constant from `"v1"` to `"v2"`.

    7. Add static method `_compute_confidence_level(queries_per_engine: int) -> str`:
       - 0 queries: return "not_measured"
       - 1-4 queries: return "low"
       - 5-9 queries: return "medium"
       - 10+ queries: return "high"

    IMPORTANT: Do NOT add scipy or any new dependency. The confidence level is a simple threshold, not a statistical interval.

    IMPORTANT: Do NOT increase query count or duplicate queries. The existing 10-15 diverse queries per engine already satisfy VIS-02. This is about transparency, not more queries.

       ```python
       def _build_per_engine_breakdown(per_engine_scores: dict) -> list[dict]:
           """Build structured per-engine breakdown from JSONB data.

           Handles both legacy format ({"openai": 75}) and
           new enriched format ({"openai": {"score": 75, ...}}).
           """
           from app.schemas.audit import ENGINE_DISPLAY_NAMES
           breakdown = []
           for engine_key, data in per_engine_scores.items():
               if isinstance(data, dict):
                   # New enriched format
                   entry = {
                       "engine_key": engine_key,
                       "display_name": ENGINE_DISPLAY_NAMES.get(engine_key, engine_key),
                       **data,
                   }
               else:
                   # Legacy format: data is just an integer score
                   entry = {
                       "engine_key": engine_key,
                       "display_name": ENGINE_DISPLAY_NAMES.get(engine_key, engine_key),
                       "score": int(data),
                       "queries_sent": 0,
                       "queries_with_mentions": 0,
                       "mention_rate": 0,
                       "total_mentions": 0,
                       "avg_confidence": 0,
                       "confidence_level": "unknown",
                       "skipped": False,
                       "skip_reason": None,
                   }
               breakdown.append(entry)
           return breakdown
       ```
