<task type="auto">
  <name>Task 1: Integrate design system fonts and standardize color tokens</name>
  <files>frontend/nuxt.config.ts, frontend/tailwind.config.js, frontend/assets/css/main.css</files>
  <action>
1. In `nuxt.config.ts`, add Google Fonts link tags to `app.head.link`:
   - Preconnect to `fonts.googleapis.com` and `fonts.gstatic.com` (with crossorigin)
   - Load stylesheet: `https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;500;600;700&family=Fira+Sans:wght@300;400;500;600;700&display=swap`

2. In `tailwind.config.js`, add `fontFamily` to `theme.extend`:
   ```
   fontFamily: {
     mono: ['"Fira Code"', 'ui-monospace', 'monospace'],
     sans: ['"Fira Sans"', 'ui-sans-serif', 'sans-serif'],
   }
   ```

3. In `main.css`, ensure base font is applied:
   - Add `body { font-family: 'Fira Sans', sans-serif; }` via Tailwind's `@layer base`
   - Score displays and data numbers should use `font-mono` class (Fira Code)

4. Search ALL .vue files for inline hex colors (`#1E40AF`, `#1E3A8A`, `#3B82F6`, `#F59E0B`) and replace with Tailwind config references:
   - `#1E40AF` -> `primary-800` (bg-primary-800, text-primary-800, etc.)
   - `#1E3A8A` -> `primary-900`
   - `#3B82F6` -> `primary-500`
   - `#F59E0B` -> `warning-500`
   - Focus rings: `focus-visible:ring-[#1E40AF]` -> `focus-visible:ring-primary-800`
   Do NOT change colors in tailwind.config.js itself (those are the source definitions).

5. Audit all .vue files for missing `cursor-pointer` on interactive elements (buttons, links styled as buttons, select dropdowns). Add where missing.

  <name>Task 2: Implement responsive sidebar with collapse and mobile overlay</name>
  <files>frontend/layouts/dashboard.vue</files>
  <action>
Refactor `layouts/dashboard.vue` to support three responsive modes using `useMediaQuery` from `@vueuse/core` (already installed):

1. **Import and setup:**
   ```
   import { useMediaQuery } from '@vueuse/core'
   const isDesktop = useMediaQuery('(min-width: 1024px)')
   const sidebarOpen = ref(true)
   ```
   Auto-collapse sidebar when transitioning from desktop to tablet/mobile:
   ```
   watch(isDesktop, (desktop) => { sidebarOpen.value = desktop })
   ```

2. **Sidebar behavior:**
   - Desktop (>=1024px): Full `w-64` sidebar, always visible
   - Tablet/Mobile (<1024px): Sidebar hidden by default. When toggled open, shows as overlay with backdrop
   - Collapsed state on tablet: `w-0 -translate-x-full` with smooth transition (`transition-all duration-200`)
   - Open state on tablet: `w-64 translate-x-0` positioned fixed with z-30

3. **Hamburger toggle button:**
   Add a `Bars3Icon` (from @heroicons/vue/24/outline) button in the top bar header, visible only on `lg:hidden`. Clicking toggles `sidebarOpen`.

4. **Mobile overlay backdrop:**
   When sidebar is open on non-desktop: render a `fixed inset-0 bg-black/50 z-20` div that closes sidebar on click.

5. **Main content margin:**
   - Desktop with sidebar open: `lg:ml-64`
   - Desktop with sidebar closed or tablet/mobile: `ml-0`
   - Transition: `transition-all duration-200`

6. **Navigation items in collapsed state:**
   When sidebar is open, show icon + label. The sidebar only has two states: fully open (w-64) or fully closed (off-screen). No icon-only mode needed -- that adds complexity without value for v2.
