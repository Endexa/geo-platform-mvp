    Class `AuthorityScorer(BaseScorer)`:

    `async def score_page(self, page_data: dict) -> list[ScoringCriterionResult]`:
    - page_data has: url, domain, html, crawl_data, main_content, internal_links (list of discovered internal links from orchestrator)
    - Call all 15 criteria methods, collecting results
    - For external API calls, use asyncio semaphore (max 3 concurrent) to avoid rate limiting
    - Return list of 15 results

    **E-E-A-T / Entity Signals (A1-A8):**

    **A1: Author bios with credentials (GRADIENT)**
    - Method: `def _check_author_bios(self, soup: BeautifulSoup, schemas: list[dict]) -> ScoringCriterionResult`
    - Detect author info: schema.org Person/author, <address> with author class, byline patterns ("By {Name}", "Written by", "Author:"), bio sections near author name
    - Score: author with credentials (jobTitle, affiliation) = 100, author name only = 50, no author = 0
    - Human summary: "Author {name} identified with credentials -- strong E-E-A-T signal"

    **A2: Published/modified dates (GRADIENT)**
    - Method: `def _check_dates(self, soup: BeautifulSoup, schemas: list[dict]) -> ScoringCriterionResult`
    - Check: <time> elements, schema.org datePublished/dateModified, meta tags, visible date patterns
    - Score: both published and modified dates visible = 100, only published = 70, dates in schema but not visible = 40, no dates = 0
    - Human summary: "Published: {date}, Modified: {date} -- dates visible to both humans and AI"

    **A3: Knowledge Graph presence (GRADIENT)**
    - Method: `async def _check_knowledge_graph(self, domain: str, brand_name: str) -> ScoringCriterionResult`
    - Call Google Knowledge Graph Search API: `https://kgsearch.googleapis.com/v1/entities:search?query={brand_name}&key={GOOGLE_API_KEY}&limit=3&indent=True`
    - If GOOGLE_API_KEY is empty, return _not_checked with reason "Google API key not configured"
    - Check if any result matches the domain (look in detailedDescription.url or result.url)
    - Score: found matching entity = 100, entity found but no domain match = 40, not found = 0
    - On API error: return _not_checked

    **A4: Wikidata QID linkage (GRADIENT)**
    - Method: `async def _check_wikidata(self, brand_name: str, domain: str) -> ScoringCriterionResult`
    - Call Wikidata API: `https://www.wikidata.org/w/api.php?action=wbsearchentities&search={brand_name}&language=en&format=json&limit=5`
    - Check if any result description or sitelinks match the brand
    - Score: QID found with matching description = 100, QID found but uncertain match = 40, not found = 0
    - On error: return _not_checked

    **A5: Wikipedia page/backlinks (GRADIENT)**
    - Method: `async def _check_wikipedia(self, brand_name: str) -> ScoringCriterionResult`
    - Call Wikipedia API: `https://en.wikipedia.org/w/api.php?action=query&titles={brand_name}&prop=extracts&exintro=true&format=json`
    - Check if page exists (not a "missing" page)
    - Score: dedicated Wikipedia page = 100, mentioned in other pages = 50, not found = 0
    - On error: return _not_checked

    **A6: Review platform profiles (GRADIENT)**
    - Method: `def _check_review_profiles(self, schemas: list[dict], soup: BeautifulSoup) -> ScoringCriterionResult`
    - Check for links/references to: g2.com, trustpilot.com, capterra.com, glassdoor.com, yelp.com
    - Check sameAs links in Organization schema for review platforms
    - Check for <a> links pointing to these domains
    - Score: 3+ platforms = 100, 2 = 70, 1 = 40, 0 = 0
    - Human summary: "Present on {N} review platforms ({list})"

    **A7: Brand search volume signal (GRADIENT)**
    - Method: `def _check_brand_signal(self, crawl_data: dict, schemas: list[dict]) -> ScoringCriterionResult`
    - This is a proxy since we cannot check actual search volume without paid APIs
    - Use proxy signals: branded title tag (brand name in <title>), strong Organization schema (name, url, logo), social profiles linked, domain age indicators
    - Score based on proxy signal strength: 4+ signals = 80, 3 = 60, 2 = 40, 1 = 20, 0 = 0
    - Note in technical_detail: "Proxy signal -- actual brand search volume requires third-party data"

    **A8: E-E-A-T composite score (GRADIENT)**
    - Method: `def _compute_eeat_composite(self, results: list[ScoringCriterionResult]) -> ScoringCriterionResult`
    - Composite of A1-A7 checked results (weighted average of the ones that were checked)
    - Score: average of checked A1-A7 scores
    - Human summary: "E-E-A-T composite: {score}/100 based on {N} signals checked"

    **SEO Fundamentals (S1-S15):**

    **S1: SSL/HTTPS (BINARY)**
    - `def _check_ssl(self, url: str) -> ScoringCriterionResult` -- check if URL starts with https

    **S2: Canonical tags (BINARY)**
    - `def _check_canonical(self, soup: BeautifulSoup) -> ScoringCriterionResult` -- check for <link rel="canonical">

    **S3: Meta title optimization (GRADIENT)**
    - `def _check_meta_title(self, soup: BeautifulSoup, crawl_data: dict) -> ScoringCriterionResult` -- check <title> exists, length 50-60 chars ideal, contains brand name. Score: optimal length+brand = 100, exists but suboptimal = 50, missing = 0

    **S4: Meta description quality (GRADIENT)**
    - `def _check_meta_description(self, soup: BeautifulSoup) -> ScoringCriterionResult` -- check <meta name="description">, length 150-160 chars ideal. Score: optimal = 100, exists but suboptimal = 50, missing = 0

    **S5: XML sitemap presence (BINARY)**
    - `async def _check_sitemap(self, domain: str) -> ScoringCriterionResult` -- check https://{domain}/sitemap.xml via HEAD request. Score: 200 = 100, not found = 0

    **S6: Open Graph tags (GRADIENT)**
    - `def _check_og_tags(self, crawl_data: dict) -> ScoringCriterionResult` -- check og:title, og:description, og:image, og:type, og:url. Score: 5/5 = 100, 4 = 80, 3 = 60, 2 = 40, 1 = 20, 0 = 0

    **S7: Mobile friendliness (GRADIENT)**
    - `def _check_mobile(self, soup: BeautifulSoup) -> ScoringCriterionResult` -- check viewport meta tag, responsive design indicators (no fixed-width). Score: viewport present + responsive = 100, viewport only = 60, neither = 0

    **S8: Internal linking score (GRADIENT)**
    - `def _check_internal_links(self, soup: BeautifulSoup, domain: str) -> ScoringCriterionResult` -- count internal links on the page. Score: 20+ = 100, 10-19 = 70, 5-9 = 40, 1-4 = 20, 0 = 0

    **S9: Backlink profile proxy (GRADIENT)**
    - `def _check_backlink_proxy(self, page_data: dict) -> ScoringCriterionResult` -- use proxy signals per research recommendation:
      - Internal link count to this page (from page_data["internal_link_count"])
      - sameAs link count from Organization schema
      - Outbound links to authoritative domains (.edu, .gov, wikipedia.org)
    - Composite score from these three signals
    - Technical detail notes: "Proxy signal -- real DR/DA requires paid API (Ahrefs/Moz)"

    **S10: Referring domains proxy (GRADIENT)**
    - `def _check_referring_domains_proxy(self, page_data: dict, schemas: list[dict]) -> ScoringCriterionResult` -- count sameAs platforms + external link diversity
    - Similar proxy approach to S9 but focused on domain diversity signals

    **S11: Core Web Vitals - LCP (GRADIENT)**
    - `async def _check_cwv(self, url: str) -> ScoringCriterionResult` -- call Google PageSpeed Insights API
    - URL: `https://www.googleapis.com/pagespeedonline/v5/runPagespeed?url={url}&category=performance&strategy=mobile`
    - Use GOOGLE_API_KEY if available (optional -- API works without key at lower rate limits)
    - Extract LCP from lighthouseResult.audits.largest-contentful-paint.numericValue
    - Score: LCP <2.5s = 100, 2.5-4s = linear 50-100, >4s = linear 0-50
    - On error/no key: return _not_checked
    - IMPORTANT: Only call PageSpeed API for the homepage (first page), not all 25 pages -- per research pitfall on rate limits. Cache result for all pages on same domain.

    **S12: URL structure quality (GRADIENT)**
    - `def _check_url_structure(self, url: str) -> ScoringCriterionResult` -- check: no query params, lowercase, no special chars, readable words, reasonable depth (<4 levels). Score based on violations.

    **S13: Image alt text coverage (GRADIENT)**
    - `def _check_alt_text(self, soup: BeautifulSoup) -> ScoringCriterionResult` -- count <img> tags with and without alt attributes. Score: 100% coverage = 100, linear scale. Exclude decorative images (role="presentation", alt="").

    **S14: Broken links (GRADIENT)**
    - `def _check_broken_links(self, soup: BeautifulSoup) -> ScoringCriterionResult` -- count href="#" and obviously broken patterns (empty href, javascript:void). Do NOT make HTTP requests for each link (too expensive for 25 pages). Just check for patterns.
    - Score: 0 suspicious links = 100, 1-2 = 70, 3-5 = 40, 5+ = 10

    **S15: Orphan pages detection (GRADIENT)**
    - `def _check_orphan_pages(self, page_data: dict) -> ScoringCriterionResult` -- check if the current page has internal_link_count > 0 (linked from other pages). Score: 5+ internal links to this page = 100, 2-4 = 70, 1 = 40, 0 = 0 (orphan page)
