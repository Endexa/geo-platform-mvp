    - Import httpx for llms.txt fetch
    - Import BeautifulSoup from bs4
    - Import extruct for JSON-LD extraction (with graceful import)
    - Import loguru logger

    Define schema type tier classification as module-level dict:
    ```python
    SCHEMA_TIERS = {
        "Foundation": ["Organization", "WebSite", "BreadcrumbList", "WebPage"],
        "Content": ["Article", "BlogPosting", "FAQPage", "HowTo", "Product", "Offer", "Review"],
        "Supplementary": ["Person", "ClaimReview", "Event", "VideoObject", "ImageObject"],
    }
    ```

    Define required fields per schema type for completeness checking:
    ```python
    SCHEMA_REQUIRED_FIELDS = {
        "Organization": ["name", "url"],
        "FAQPage": ["mainEntity"],
        "Article": ["headline", "author", "datePublished"],
        "BlogPosting": ["headline", "author", "datePublished"],
        "HowTo": ["name", "step"],
        "Product": ["name"],
        "BreadcrumbList": ["itemListElement"],
        "Person": ["name"],
        "ClaimReview": ["claimReviewed", "reviewRating"],
    }
    ```

    Class `StructuredDataScorer(BaseScorer)`:

    `async def score_page(self, page_data: dict) -> list[ScoringCriterionResult]`:
    - page_data has: url, domain, html, crawl_data (with schema_org field from CrawlerService extruct extraction)
    - Extract JSON-LD from crawl_data["schema_org"] (already parsed by CrawlerService)
    - Also re-extract from HTML using extruct as backup in case crawl_data is incomplete
    - Call all 13 criteria methods and return collected results

    **SD1: Organization schema present (BINARY)**
    - Method: `def _check_organization(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type == "Organization" or "LocalBusiness" (which inherits from Organization)
    - Score: 100 if found, 0 if not
    - Human summary: "Organization schema found -- AI can identify your brand entity" or "No Organization schema -- AI may not recognize your brand"
    - Evidence: {found, type, name, url}

    **SD2: sameAs links (GRADIENT)**
    - Method: `def _check_same_as(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Count sameAs links in Organization schema pointing to authoritative platforms
    - Known platforms: linkedin.com, twitter.com/x.com, facebook.com, wikipedia.org, wikidata.org, github.com, youtube.com, g2.com, trustpilot.com, crunchbase.com
    - Score: 0 links = 0, 1-2 = 40, 3-4 = 60, 5-6 = 80, 7+ = 100
    - Human summary: "{N} platform links -- {Strong/Moderate/Weak/No} multi-platform entity signal"
    - Evidence: {count, platforms_found, platforms_missing}

    **SD3: FAQPage schema (BINARY with bonus)**
    - Method: `def _check_faqpage(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type == "FAQPage" with mainEntity containing Question/Answer pairs
    - Score: 100 if valid FAQPage with 3+ Q&A pairs, 70 if 1-2 pairs, 0 if not found
    - Human summary: "FAQPage schema with {N} Q&A pairs -- 3.2x higher AI citation rate (BrightEdge)" or "No FAQPage schema -- missing highest-impact structured data for AI citations"
    - Evidence: {found, question_count, questions_preview}

    **SD4: Article/BlogPosting schema (BINARY)**
    - Method: `def _check_article(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type in ("Article", "BlogPosting", "NewsArticle", "TechArticle")
    - Score: 100 if found, 0 if not
    - Human summary: "{type} schema found -- E-E-A-T signals (author, dates)" or "No Article schema"
    - Evidence: {found, type, has_author, has_date}

    **SD5: HowTo schema (BINARY)**
    - Method: `def _check_howto(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type == "HowTo" with step array
    - Score: 100 if found with steps, 50 if found without steps, 0 if not found
    - Human summary: "HowTo schema with {N} steps -- AI can extract step-by-step instructions"

    **SD6: BreadcrumbList schema (BINARY)**
    - Method: `def _check_breadcrumb(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type == "BreadcrumbList" with itemListElement
    - Score: 100 if found with items, 0 if not
    - Human summary: "BreadcrumbList schema found -- site structure is clear to AI"

    **SD7: JSON-LD validation (GRADIENT)**
    - Method: `def _check_jsonld_validity(self, html: str) -> ScoringCriterionResult`
    - Find all <script type="application/ld+json"> tags in HTML
    - For each: try json.loads(). Count valid vs invalid.
    - Check for common issues: missing @context, missing @type, invalid JSON syntax
    - Score: all valid = 100, some invalid = 50, all invalid or none found = 0
    - Human summary: "{N}/{M} JSON-LD blocks valid -- {All valid/Some errors/No structured data}"
    - Evidence: {total_blocks, valid_blocks, invalid_blocks, errors}

    **SD8: Product/Offer schema (BINARY)**
    - Method: `def _check_product(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type in ("Product", "Offer", "SoftwareApplication", "Service")
    - Score: 100 if found, 0 if not (only relevant for commercial pages)
    - Human summary: "Product schema found" or "No Product/Offer schema (may not be relevant for this page type)"
    - Evidence: {found, type, has_price, has_name}

    **SD9: Person schema (GRADIENT)**
    - Method: `def _check_person(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type == "Person" or author objects within Article schemas
    - Check for credential fields: jobTitle, affiliation, sameAs
    - Score: 100 if Person with credentials, 60 if Person without credentials, 30 if author name only (inline in Article), 0 if no author info
    - Human summary: "Author identified as {name} with credentials -- strong E-E-A-T signal"

    **SD10: ClaimReview schema (BINARY)**
    - Method: `def _check_claim_review(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Look for @type == "ClaimReview"
    - Score: 100 if found, 0 if not (only relevant for fact-checking content)
    - This is a supplementary signal; most sites will not have this.

    **SD11: Structured data coverage (GRADIENT)**
    - Method: `def _check_coverage(self, schemas: list[dict]) -> ScoringCriterionResult`
    - Count how many schema types are used across the page
    - Classify found types by tier
    - Score: 0 types = 0, 1 (any tier) = 30, 2-3 types = 50, 4-5 types = 70, 6+ types with Foundation + Content tiers = 100
    - Human summary: "{N} schema types across {tiers} tiers -- {Comprehensive/Good/Basic/No} structured data"
    - Evidence: {total_types, types_found, tiers_represented}

    **SD12: llms.txt presence (BINARY)**
    - Method: `async def _check_llms_txt(self, domain: str) -> ScoringCriterionResult`
    - Fetch https://{domain}/llms.txt via httpx (timeout 5s)
    - Validate format: should contain text content (not HTML), should have title line starting with "#"
    - Score: 100 if present and valid format, 50 if present but malformed, 0 if not found
    - Human summary: "llms.txt found -- low-cost AI accessibility signal (844K+ sites adopted)" or "No llms.txt -- optional but growing standard"
    - Evidence: {found, status_code, has_title, line_count}

    **SD13: llms-full.txt presence (BINARY)**
    - Method: `async def _check_llms_full_txt(self, domain: str) -> ScoringCriterionResult`
    - Fetch https://{domain}/llms-full.txt via httpx (timeout 5s)
    - Score: 100 if present, 0 if not found
    - Human summary: "llms-full.txt found -- full content accessible to AI tools" or "No llms-full.txt"
    - Evidence: {found, status_code, content_length}

    Helper method:
    - `def _find_schemas_by_type(self, schemas: list[dict], types: list[str]) -> list[dict]` -- searches schema_org list (may be nested with @graph) for matching @type values. Handles both flat and @graph-wrapped JSON-LD.
