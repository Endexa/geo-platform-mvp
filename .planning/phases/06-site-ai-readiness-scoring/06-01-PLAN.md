      - Abstract method: `async def score_page(self, page_data: dict) -> list[ScoringCriterionResult]` -- scores a single page against all criteria in the category
      - Concrete method: `def compute_category_score(self, results: list[ScoringCriterionResult]) -> float` -- weighted average of checked criteria only (exclude checked=False). Return `sum(r.score for r in checked) / len(checked)` or 0.0 if no checked results.
      - Concrete helper: `def _not_checked(self, criterion_id: str, criterion_name: str, reason: str) -> ScoringCriterionResult` -- returns a ScoringCriterionResult with checked=False, score=0, human_summary including reason

    Create `backend/app/services/scoring/scoring_orchestrator.py`:
    - Import BaseScorer, ScoringCriterionResult from base_scorer
    - Import CrawlerService from app.services.crawler_service
    - Import settings from app.core.config
    - Import PageScore, CriterionResult (SQLAlchemy model) from app.models
    - Import asyncio, loguru logger
    - Class `ScoringOrchestrator`:
      - `CATEGORY_WEIGHTS` class dict: crawlability=0.25, content_structure=0.25, structured_data=0.20, authority=0.15, ai_visibility=0.15
      - `__init__(self, db)` -- takes SQLAlchemy session, initializes empty dict `self.scorers: dict[str, BaseScorer]` -- scorers registered by Plans 02-05
      - `def register_scorer(self, category: str, scorer: BaseScorer)` -- adds scorer to self.scorers dict
      - `async def score_audit(self, audit_id: str, crawl_data: dict, visibility_score: int) -> dict` -- main entry:
        1. Discover internal links from initial crawl_data HTML using `_discover_internal_links()`
        2. Select top pages by link count up to `settings.SCORING_CRAWL_CAP` (homepage always included)
        3. Crawl selected pages using CrawlerService (reuse existing async crawl method, concurrent with asyncio.Semaphore max 5)
        4. For each crawled page, run all registered scorers via `_score_page()`
        5. Store PageScore and CriterionResult records in DB
        6. For discovered-but-not-scored pages, store PageScore with was_scored=False
        7. Compute optimization score via `compute_optimization_score()`
        8. Return dict with optimization_score, page_count, pages_scored, pages_discovered
      - `async def _score_page(self, page_data: dict) -> dict` -- runs all registered scorers on a single page, returns dict of category -> (score, list[ScoringCriterionResult])
      - `def _discover_internal_links(self, html: str, base_url: str, domain: str) -> list[tuple[str, int]]` -- extract internal links with count, sorted desc. Normalize URLs (strip fragments, trailing slashes). Skip non-content URLs (/login, /signup, /admin, /api/, /assets/, /static/, .pdf, .jpg, .png, .css, .js). Same domain only.
      - `def compute_optimization_score(self, page_category_scores: list[dict], visibility_score: int) -> int` -- compute weighted formula with weakest-link aggregation:
        1. For each page, compute weighted category score (crawlability*0.25 + content_structure*0.25 + structured_data*0.20 + authority*0.15)
        2. Aggregate across pages: `weakest_link(page_scores) = 0.6 * mean + 0.4 * min`
        3. Add AI visibility: `site_technical_score + visibility_score * 0.15`
        4. Clamp to 0-100, return rounded int
