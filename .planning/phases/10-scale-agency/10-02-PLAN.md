  <action>
1. Add `MultiBrandOverviewEntry` schema to `backend/app/schemas/brand.py`:
   - `brand_id`: UUID
   - `brand_name`: str
   - `brand_url`: str
   - `brand_domain`: str
   - `latest_audit_id`: UUID | None
   - `combined_geo_score`: int | None (50/50 visibility + optimization blend)
   - `visibility_score`: int | None
   - `optimization_score`: int | None
   - `mention_count`: int
   - `top_issues_count`: int
   - `audit_count`: int
   - `last_audited_at`: datetime | None

2. Add `MultiBrandOverviewResponse` schema:
   - `brands`: list[MultiBrandOverviewEntry]
   - `total_brands`: int

3. Add `get_multi_brand_overview(self, user_id: str) -> list[dict]` method to BrandService in `backend/app/services/brand_service.py`:
   - Query all brands for user_id
   - For each brand, find the latest completed audit (Audit where brand_id matches, status="completed", order by created_at desc, limit 1)
   - For the latest audit, fetch lightweight metrics directly (NOT calling full DashboardService.get_overview() per Pitfall 2):
     * `visibility_score`: from VisibilityScore table where audit_id matches, get overall_score
     * `optimization_score`: from Audit.optimization_score column
     * `combined_geo_score`: round((visibility * 0.5 + optimization * 0.5)) if both exist
     * `mention_count`: count BrandMention where audit_id matches (via AuditQuery join)
     * `top_issues_count`: count AuditRecommendation where audit_id matches and status="open" and priority="high"
   - Also count total audits per brand: `db.query(func.count(Audit.id)).filter(Audit.brand_id == brand.id).scalar()`
   - Return list of dicts matching MultiBrandOverviewEntry fields
   - Import VisibilityScore, Audit, AuditRecommendation, BrandMention, AuditQuery as needed

4. Add `GET /overview` endpoint to `backend/app/api/brands.py`:
   - Requires auth (Depends get_current_active_user)
   - Calls `BrandService(db).get_multi_brand_overview(str(current_user.id))`
   - Returns MultiBrandOverviewResponse
   - This is the key endpoint for the cross-brand comparison dashboard
  </action>

    Verify GET /overview route exists in brands.py router.
