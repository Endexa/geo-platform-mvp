       Replace the `except` block that returns `score=50` with a call to `self._not_checked("C9", "Server-side rendering", f"Playwright failed: {str(e)[:200]}")`.     2. **Fix link discovery field (scoring_orchestrator.py, line 84):**
       Change `html = crawl_data.get("main_content", "")` to `html = crawl_data.get("html", "")`. The main_content field contains extracted text with HTML tags stripped, so BeautifulSoup finds zero anchor tags. The html field contains full HTML with links intact. Also update the comment on line 87 to reflect this is now using full HTML.

    3. **Add Playwright cleanup after scoring (audit_tasks.py, after line 227):**
       After the `scoring_result = asyncio.run(orchestrator.score_audit(...))` call completes, add cleanup for the CrawlabilityScorer's Playwright browser. Access the scorer via the orchestrator: `if "crawlability" in orchestrator.scorers: orchestrator.scorers["crawlability"].cleanup()`. Wrap in try/except so cleanup failure does not crash the pipeline. This prevents chromium process leaks in long-running Celery workers.

    Do NOT modify the scoring algorithm, category weights, or any other scorer. These are three surgical fixes to known bugs identified in research.
