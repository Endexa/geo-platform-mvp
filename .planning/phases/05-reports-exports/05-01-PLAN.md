Create `backend/app/services/report_service.py` with class `ReportService`:

**Constructor:** Takes `db: Session`. Sets up Jinja2 `Environment` with `FileSystemLoader` pointing to `app/templates`, with `autoescape=True`.

**Private method `_build_context(self, audit_id: str) -> dict`:**
- Load Audit with joinedload for page_scores (with criterion_results), visibility_score, recommendations (via backref)
- Raise HTTPException 404 if audit not found or not COMPLETED
- Build context dict with:
  - `domain`, `url`, `generated_at` (current UTC datetime formatted), `completed_at` (formatted or None)
  - `visibility_score`: overall score from VisibilityScore (default 0)
  - `optimization_score`: Audit.optimization_score (default 0)
  - `combined_geo_score`: weighted combination = `round(visibility * 0.15 + optimization * 0.85)` -- from CLAUDE.md scoring weights (AI Visibility 15% of total)
  - `mention_count`: from VisibilityScore (default 0)
  - `per_engine_scores`: dict from VisibilityScore.per_engine_scores; for enriched format extract just the score ints for template display (e.g., `{"ChatGPT": 75, "Claude": 62}`) using ENGINE_DISPLAY_NAMES from schemas/audit.py
  - `per_engine_breakdown`: list of enriched dicts if new format, for detailed engine table
  - `confidence_level`: from VisibilityScore
  - `category_averages`: compute averages from PageScore objects: crawlability, content_structure, structured_data, authority
  - `recommendations`: list of AuditRecommendation objects ordered by priority then gap_score desc
  - `content_gaps`: from Audit.content_gaps JSONB (default [])
  - `all_competitors`: load DiscoveredCompetitor records for this audit
  - `competitor_audits`: load CompetitorAudit records for this audit
  - `executive_summary`: generate a text paragraph summarizing key findings:
    - "Audit of {domain} scored {optimization}/100 for optimization and {visibility}/100 for AI visibility."
    - If optimization >= 70: "The site demonstrates strong optimization fundamentals."
    - If optimization >= 40 and < 70: "The site has a moderate optimization foundation with room for improvement."
    - If optimization < 40: "The site needs significant optimization work."
    - "Top priority: {top_rec.summary}" (first high-priority recommendation, or "No critical issues found")
    - "{len(recommendations)} recommendations identified across {len(set(r.category for r in recs))} categories."
  - `pages_scored`: count of PageScore with was_scored=True
  - `pages_discovered`: total PageScore count

**Method `render_html(self, audit_id: str) -> str`:**
- Call `_build_context(audit_id)`
- Get template `audit_report.html`
- Return `template.render(**context)`

**Method `render_pdf(self, audit_id: str) -> bytes`:**
- Call `render_html(audit_id)`
- Return `weasyprint.HTML(string=html_string).write_pdf()`

**Method `export_csv(self, audit_id: str, fields: list[str] | None = None, grouping: str = "category", epic_link: str | None = None) -> str`:**
- Load AuditRecommendation records for audit_id, ordered by priority then gap_score desc
- If no recommendations, return CSV with just headers
- Default fields: `["Summary", "Description", "Priority", "Labels", "Issue Type", "Component"]`
- If `epic_link` provided, add "Epic Link" to fields
- Priority mapping: high -> "Highest", medium -> "Medium", low -> "Low"
- Build rows:
  - Summary = rec.summary
  - Description = "\n".join(rec.action_steps or []) + ("\n\nCode:\n" + rec.code_snippet if rec.code_snippet else "")
  - Priority = mapped priority
  - Labels = rec.category (e.g., "crawlability")
  - Issue Type = "Task"
  - Component = rec.criterion_name
  - Epic Link = epic_link value if provided
- If grouping == "priority": sort by priority before writing
- If grouping == "page": sort by page_url before writing (default is already by category from the query)
- Write to StringIO with BOM prefix (`\ufeff`) for Excel compatibility
- Use `csv.DictWriter(output, fieldnames=fields, extrasaction='ignore')`
- Return `output.getvalue()`

Create `backend/app/api/reports.py`:

**Imports:** FastAPI router, Response, Depends, HTTPException, Session from get_db, Profile from security, require_tier and SubscriptionTier from dependencies, ReportService from services, Audit model, loguru logger.

**Router:** `router = APIRouter(prefix="/api/v1/reports", tags=["reports"])`

**Helper `_verify_audit_ownership`:** Same pattern as in recommendations.py -- load Audit, check user_id matches current_user.id, raise 404 if not found, 403 if wrong user. Return Audit object.

**Endpoint 1: `GET /{audit_id}/pdf`**
- Dependencies: `Depends(require_tier(SubscriptionTier.PRO))`
- Params: audit_id str, db Session, current_user Profile
- Call `_verify_audit_ownership`, then `ReportService(db).render_pdf(audit_id)`
- Build filename: `f"endexa-report-{audit.domain.replace('.', '-')}.pdf"`
- Return `Response(content=pdf_bytes, media_type="application/pdf", headers={"Content-Disposition": f'attachment; filename="{filename}"'})`
- Log: "PDF report downloaded for audit {audit_id} by user {current_user.id}"

**Endpoint 2: `GET /{audit_id}/html`**
- Dependencies: `Depends(require_tier(SubscriptionTier.PRO))`
- Same auth/ownership pattern
- Call `ReportService(db).render_html(audit_id)`
- Build filename: `f"endexa-report-{audit.domain.replace('.', '-')}.html"`
- Return `Response(content=html_string, media_type="text/html", headers={"Content-Disposition": f'attachment; filename="{filename}"'})`

**Endpoint 3: `GET /{audit_id}/csv`**
- Dependencies: `Depends(require_tier(SubscriptionTier.PRO))`
- Same auth/ownership pattern
- Query params: `grouping: str = "category"` (one of: category, priority, page), `epic_link: str | None = None`, `fields: str | None = None` (comma-separated field names)
- Parse fields: if provided, split by comma and strip whitespace; else None (uses defaults)
- Call `ReportService(db).export_csv(audit_id, fields=parsed_fields, grouping=grouping, epic_link=epic_link)`
- Build filename: `f"endexa-recommendations-{audit.domain.replace('.', '-')}.csv"`
- Return `Response(content=csv_string, media_type="text/csv", headers={"Content-Disposition": f'attachment; filename="{filename}"'})`

**Register router in `backend/app/main.py`:**
- Add `from app.api import reports` to imports
- Add `app.include_router(reports.router, tags=["reports"])` after the payments router line
