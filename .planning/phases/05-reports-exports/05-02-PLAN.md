**Create `frontend/composables/useReports.ts`:**

Export composable `useReports()` that provides:

- `downloadPdf(auditId: string)`: GET `/api/v1/reports/{auditId}/pdf` with auth headers, handle blob response, trigger browser download with Content-Disposition filename
- `downloadHtml(auditId: string)`: GET `/api/v1/reports/{auditId}/html`, same blob download pattern
- `downloadCsv(auditId: string, options?: { grouping?: string, epicLink?: string, fields?: string })`: GET `/api/v1/reports/{auditId}/csv` with query params, same download pattern
- `isDownloading`: ref(false) -- loading state
- `downloadError`: ref(null) -- error message

Download pattern:
```typescript
const response = await $fetch.raw(`${apiBase}/reports/${auditId}/pdf`, {
  headers: { Authorization: `Bearer ${token}` },
  responseType: 'blob',
})
const blob = response._data
const filename = response.headers.get('content-disposition')?.split('filename=')[1]?.replace(/"/g, '') || 'report.pdf'
const url = URL.createObjectURL(blob)
const a = document.createElement('a')
a.href = url
a.download = filename
a.click()
URL.revokeObjectURL(url)
```

Handle 402 errors specifically: set `downloadError` to "Upgrade to Pro to download reports".
