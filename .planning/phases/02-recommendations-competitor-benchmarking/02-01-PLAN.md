<objective>
Create a vertical classifier that detects website industry type from crawl data, enhance the recommendation engine with industry-aware filtering and impact delta calculation, and add the required database columns.

Purpose: Users currently receive irrelevant schema recommendations (e.g., LocalBusiness schema for a SaaS site). The vertical classifier enables filtering out inapplicable advice, and impact deltas give users a concrete "fix this to gain ~X points" estimate instead of just generic research percentages.

Output: `vertical_classifier.py` service, enhanced `recommendation_engine.py` with vertical filter + impact delta, Alembic migration for new columns, and TDD tests for both.
</objective>
