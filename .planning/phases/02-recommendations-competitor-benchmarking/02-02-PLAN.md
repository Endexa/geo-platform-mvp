<objective>
Add cross-audit competitor persistence by linking DiscoveredCompetitor records to Brand entities, enabling share-of-voice tracking over time.

Purpose: Currently each audit creates fresh competitor records with no link to previous audits. Users cannot track how their competitive positioning changes over time. By normalizing competitors through the Brand model, the same competitor entity persists across audits and SOV trends become visible.

Output: Enhanced Brand model with `is_competitor` flag, DiscoveredCompetitor with `competitor_brand_id` FK, brand linking logic in CompetitorService, SOV trend API endpoint, Alembic migration, and TDD tests.
</objective>

    1. Add `link_competitor_to_brand()` method to `CompetitorService` in `backend/app/services/competitor_service.py`:
       - Signature: `def link_competitor_to_brand(self, db: Session, competitor: DiscoveredCompetitor, user_id: str) -> None`
       - Matching strategy (in priority order):
         a. **Domain match** (strongest signal): If competitor.resolved_url exists, extract domain via `urlparse(competitor.resolved_url).netloc`. Query Brand where user_id matches AND domain matches. If found, set competitor.competitor_brand_id = brand.id and return.
         b. **Exact name match** (case-insensitive): Query Brand where user_id matches AND `func.lower(Brand.name) == competitor.entity_name.lower()`. If found, link and return.
         c. **Fuzzy name match**: Import rapidfuzz. Query all Brands for this user_id. Use `fuzz.token_set_ratio(brand.name, competitor.entity_name)`. If any score > 90, link to the highest-scoring match and return.
         d. **Create new Brand**: Create Brand with name=competitor.entity_name, user_id=user_id, domain=extracted_domain (or None), url=competitor.resolved_url (or ""), is_competitor=True. Flush to get ID. Set competitor.competitor_brand_id = brand.id.
       - Import `from urllib.parse import urlparse` and `from sqlalchemy import func`

    2. Add `link_audit_competitors_to_brands()` method to `CompetitorService`:
