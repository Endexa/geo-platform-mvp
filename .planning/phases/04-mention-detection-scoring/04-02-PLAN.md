    **Insert after Stage 3 (dispatch) and before the COMPLETED block:**

    ```python
    # Stage 4: Analyze mentions and compute visibility score
    logger.info("Audit {}: starting mention analysis", audit_id)
    audit.status = AuditStatus.ANALYZING.value
    db.commit()

    # Extract brand name from crawl data (same extraction used in Stage 2)
    brand_name = QueryGeneratorService.extract_brand_name(audit.crawl_data)

    # Generate brand variants
    detector = MentionDetectorService()
    brand_variants = detector.generate_brand_variants(brand_name)
    logger.info("Audit {}: analyzing mentions for brand '{}' ({} variants)", audit_id, brand_name, len(brand_variants))

    # Load successful engine responses for analysis
    responses = (
        db.query(EngineResponse)
        .join(AuditQuery)
        .filter(AuditQuery.audit_id == audit_id)
        .filter(EngineResponse.error_message.is_(None))
        .all()
    )

    # Detect mentions in each response
    total_mentions = 0
    for response in responses:
        mentions = detector.detect_mentions(
            response_text=response.response_text,
            brand_name=brand_name,
            brand_variants=brand_variants,
        )
        for mention_data in mentions:
            mention = BrandMention(
                engine_response_id=response.id,
                **mention_data,
            )
            db.add(mention)
            total_mentions += 1
    db.commit()
    logger.info("Audit {}: detected {} mentions across {} responses", audit_id, total_mentions, len(responses))

    # Compute visibility score
    scorer = ScoringService(db)
    score = scorer.compute_audit_score(audit_id=audit_id, total_queries=len(queries))
    db.add(score)
    db.commit()
    logger.info("Audit {}: visibility score = {}/100", audit_id, score.overall_score)
    ```

    **Update the pipeline docstring** at the top of the file to reflect 5 stages: CRAWLING -> GENERATING_QUERIES -> DISPATCHING -> ANALYZING -> COMPLETED.

    **Important:** The `queries` variable is already available from Stage 3 (loaded from DB before dispatch). Use `len(queries)` as `total_queries` for the scoring service.

    **Important:** The `brand_name` extraction in Stage 4 re-extracts from `audit.crawl_data` rather than saving it from Stage 2, because the brand_name is not persisted on the Audit model. This is a minor redundancy but avoids schema changes.
