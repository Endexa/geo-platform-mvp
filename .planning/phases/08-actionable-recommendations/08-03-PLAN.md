    **1. `frontend/components/RecommendationCard.vue`:**

    Two-tier recommendation card per user decision (default summary + expandable detail).

    Props:
    - `recommendation`: object (AuditRecommendationResponse shape)

    Emits:
    - `update-status`: { id: string, status: 'done' | 'dismissed' | 'open' }

    Structure (default view):
    ```
    +--------------------------------------------------------------------+
    | [Priority Badge] {criterion_name} -- {page_url or 'Site-wide'}     |
    |                                                   [Done] [Dismiss] |
    | "{summary}"                                                         |
    | Impact: {impact_label}  Gap: {gap_score}pts                        |
    | Competitor avg: {competitor_avg ?? 'N/A'}  Your score: {user_score} |
    |                                              [See Steps v]          |
    +--------------------------------------------------------------------+
    ```

    Priority badge colors: HIGH = red-100/red-700, MEDIUM = amber-100/amber-700, LOW = blue-100/blue-700.

    Done/Dismiss buttons:
    - "Done" button: green outline, becomes solid green when status="done", shows CheckIcon
    - "Dismiss" button: gray outline, becomes solid gray when status="dismissed", shows XMarkIcon
    - When status="done" or "dismissed", show an "Undo" button to revert to "open"

    Expanded view (v-show toggle with transition):
    - Action steps as numbered list
    - Code snippet in a `<pre>` block with bg-gray-900 text-green-400 rounded-lg p-4 font-mono text-sm (if code_snippet is not null)
    - Evidence source in italics with text-gray-500
    - Research impact inline: "Source: {evidence_source}"

    Toggle button: "See Steps" / "Hide Steps" with ChevronDownIcon rotation.

    When status="done", the card gets a subtle green-50 background and reduced opacity on the summary text (line-through or opacity-60). When status="dismissed", card gets gray-50 background and opacity-40.

    **2. `frontend/components/RecommendationProgress.vue`:**

    Props:
    - `progress`: { done: number, dismissed: number, open: number, total: number }

    Structure:
    ```
    [===================                    ] 12/28 addressed
    ```

    - Green progress bar: width = ((done + dismissed) / total * 100)%
    - Text: "{done}/{total} addressed" (dismissed counts as addressed)
    - Below the bar: "High: {n} remaining | Medium: {m} remaining | Low: {k} remaining" in small text

    Props also accept optional `byPriority`: { high: number, medium: number, low: number } for the remaining counts (filter by status="open").

    Use h-2.5 rounded-full for the bar. Transition width with `transition-all duration-300`.

    ```
    Sentiment by Engine
    ```

    Engine label mapping: openai -> "ChatGPT", anthropic -> "Claude", perplexity -> "Perplexity", gemini -> "Gemini".

    Dominant sentiment colors: positive = green-500/green-100, negative = red-500/red-100, neutral = gray-500/gray-100, mixed (no clear majority) = amber-500/amber-100.

    Show a mini bar for each engine: green portion = positive%, red = negative%, gray = neutral%. Use flex with colored segments.

    If total=0 for an engine: show "Not mentioned" in gray italic.
