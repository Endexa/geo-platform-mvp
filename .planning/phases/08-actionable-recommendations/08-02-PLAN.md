    **1. Add content gap identification to `backend/app/services/recommendation_engine.py`:**

    Add these methods to the RecommendationEngine class:

    - `identify_content_gaps(self, audit_id: str) -> list[dict]`:
      1. Load all AuditQuery records for this audit: {str(q.id): q.query_text}
      2. Find queries where user brand was mentioned: join BrandMention -> EngineResponse -> AuditQuery, filter by audit_id, collect unique AuditQuery IDs
      3. Load DiscoveredCompetitor records for this audit where is_user_brand=False
      4. Build query_to_competitors index: for each competitor, iterate queries_mentioned_in (JSONB list of query IDs), map query_id -> [competitor entity_names]
      5. Find gaps: queries where competitor appears (in query_to_competitors) but user brand does not (not in user_mentioned_query_ids)
      6. For each gap, generate a template-based mini brief via `_template_brief()`:
        - suggested_title: f"Complete Guide: {query_text.rstrip('?').capitalize()}"
        - key_points: 5 points: answer the question, include stats, add FAQPage schema, cite sources, compare to top competitors
        - target_queries: [query_text]
      7. Return list of dicts: {"query_id": str, "query_text": str, "competitors_mentioned": list[str], "brief": {"title": str, "key_points": list[str], "target_queries": list[str]}}

    - `save_content_gaps(self, audit_id: str, gaps: list[dict])`:
      1. Load the Audit record
      2. Set audit.content_gaps = gaps (JSONB column)
      3. db.flush()

    - `_template_brief(self, query_text: str, competitors: list[str]) -> dict`:
      Return dict with:
      - "title": f"Complete Guide: {query_text.rstrip('?').capitalize()}"
      - "key_points": [
          f"Answer the question: {query_text}",
          "Include statistics and data tables to support claims (+40% visibility, 4.1x citations)",
          "Add FAQPage schema with the most common related questions (+28% AI citations)",
          "Cite authoritative sources for E-E-A-T signals",
          f"Address what {', '.join(competitors[:3])} cover that you currently miss",
        ]
      - "target_queries": [query_text]

    - `export_markdown(self, audit_id: str, page_url: str | None = None) -> str`:
      1. Load AuditRecommendation records for this audit, optionally filtered by page_url
      2. Load Audit record for domain name
      3. Build Markdown string following the GSD-inspired format from 08-RESEARCH.md Pattern 5:
        - Header: "# GEO Fix Plan: {domain} - {date}"
        - Summary: N high / M medium / K low priority fixes
        - Group recommendations by priority (High, Medium, Low sections)
        - Each recommendation:
          ```
          ### Fix N: {criterion_name} -- {page_url or 'Site-wide'}
          **Evidence:** {impact_label} ({evidence_source})
          **Your score:** {user_score}/100 | **Competitor avg:** {competitor_avg or 'N/A'}/100 | **Gap:** {gap_score} points
          **Status:** {status}

          **Steps:**
          {numbered action_steps}

          {code_snippet if present, in fenced code block}

          **Acceptance criteria:**
          - [ ] Re-run audit to verify improvement
          - [ ] {criterion_name} score > {threshold}
          ```
      4. If page_url is None (full site), include all recommendations grouped by page then priority
      5. Append content gaps section if any exist:
        ```
        ## Content Gaps

        Topics where competitors are mentioned but you are not:

        ### {gap.query_text}
        **Competitors mentioned:** {competitors}
        **Suggested content:** {brief.title}
        **Key points to cover:**
        {brief.key_points as bullets}
        ```
      6. Return the complete Markdown string

    **1. Create `backend/app/api/recommendations.py`:**

    Follow project patterns from audit.py and competitors.py. All endpoints require auth via `Depends(get_current_active_user)`. All endpoints verify the audit belongs to the current user.

    Router: `router = APIRouter(prefix="/api/v1/recommendations", tags=["recommendations"])`

    Endpoints:

    - `GET /{audit_id}` -> RecommendationListResponse
      - Load audit, verify ownership (audit.user_id == current_user.id, else 403)
      - Query AuditRecommendation records for this audit_id
      - Optional query param `page_url` to filter by page
      - Optional query param `priority` to filter by priority ("high", "medium", "low")
      - Optional query param `category` to filter by category
      - Compute by_priority counts and progress counts
      - Return RecommendationListResponse

    - `PATCH /{audit_id}/{recommendation_id}` -> AuditRecommendationResponse
      - Load audit, verify ownership
      - Load AuditRecommendation by id, verify it belongs to this audit
      - Accept RecommendationStatusUpdate body
      - Update status, set updated_at
      - db.commit()
      - Return updated recommendation

    - `GET /{audit_id}/sentiment` -> SentimentSummaryResponse
      - Load audit, verify ownership
      - Call SentimentService(db).get_per_engine_summary(audit_id)
      - Return SentimentSummaryResponse

    - `GET /{audit_id}/content-gaps` -> ContentGapListResponse
      - Load audit, verify ownership
      - Read audit.content_gaps (JSONB column)
      - If None or empty, return empty list
      - Return ContentGapListResponse with gaps and total count

    - `GET /{audit_id}/export/markdown` -> Response (text/markdown)
      - Load audit, verify ownership
      - Optional query param `page_url` for single-page export
      - Call RecommendationEngine(db).export_markdown(audit_id, page_url)
      - Return Response with content_type="text/markdown", Content-Disposition header: `attachment; filename=fix-plan-{domain}.md` (or `fix-plan-{domain}-{page_slug}.md` if page_url specified)

    **2. Update `backend/app/main.py`:**
    - Import the recommendations router: `from app.api.recommendations import router as recommendations_router`
    - Include the router: `app.include_router(recommendations_router)` alongside existing routers
    - Place after the competitors router in the include order
