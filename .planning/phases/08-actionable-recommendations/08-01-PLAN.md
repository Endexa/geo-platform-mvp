    **1. `backend/app/services/recommendation_engine.py`** -- RecommendationEngine:

    Follow the code structure from 08-RESEARCH.md Pattern 1. Key elements:

    - `CRITERION_RESEARCH_MAP` dict: Hard-coded research benchmarks for each criterion ID. Include all high-impact criteria from research:
      - SD3 (FAQPage): impact_pct=320, "3.2x citation rate", evidence="BrightEdge + Frase.io", priority_base="high", threshold=60

      - CS2 (Answer-first): impact_pct=140, "+40% citations", evidence="Princeton GEO paper", priority_base="high", threshold=50
      - CS10 (Statistics density): impact_pct=140, "+40% visibility", evidence="Princeton GEO paper", priority_base="high", threshold=50
      - CS4 (Data density/tables): impact_pct=410, "4.1x AI citations", evidence="Surfer SEO 46M analysis", priority_base="high", threshold=40
      - CS11 (Quotations): impact_pct=120, "+15-25% boost", evidence="Princeton GEO paper", priority_base="medium", threshold=40
      - CS9 (Content freshness): impact_pct=320, "3.2x more citations", evidence="Industry benchmark", priority_base="medium", threshold=50
      - CS8 (Citations/references): impact_pct=125, "+20-30% visibility", evidence="Princeton GEO paper", priority_base="medium", threshold=40
      - CS1 (Heading hierarchy): impact_pct=280, "2.8x citation rate", evidence="Industry research", priority_base="high", threshold=50
      - C9 (SSR detection): impact_pct=300, "Critical for AI bot access", evidence="Otterly.ai", priority_base="high", threshold=40
      - S8 (Internal linking): impact_pct=270, "2.7x citation probability", evidence="Content cluster research", priority_base="high", threshold=40
      - A3 (Knowledge Graph): impact_pct=280, "2.8x citation likelihood", evidence="Ahrefs 75K study", priority_base="high", threshold=30
      - DEFAULT_BENCHMARK: impact_pct=105, "+5% improvement", evidence="Industry standard", priority_base="low", threshold=60

    - `CRITERION_SNIPPETS` dict: Pre-defined code snippets for the top ~10 highest-impact criteria. Examples:
      - SD3 (FAQPage): JSON-LD FAQPage template with placeholder questions
      - SD1 (Organization schema): JSON-LD Organization template with sameAs
      - C9 (SSR): Note about SSR/SSG framework configuration
      - CS5 (FAQ section): HTML FAQ section template
      - SD12 (llms.txt): llms.txt file format template
      - Other criteria get None (action_steps sufficient without code)

    - `_compute_rec_hash(criterion_id, page_url)`: SHA-256 of f"{criterion_id}|{normalized_url}", truncated to 16 chars. Normalize URL: strip trailing slash, lowercase scheme+host, keep path.

    - `class RecommendationEngine`:
      - `__init__(self, db: Session)`
      - `generate_recommendations(self, audit_id: str, user_id: str) -> list[AuditRecommendation]`:
        1. Load completed CompetitorAudit records for this audit
        2. Compute competitor category averages via `_compute_competitor_averages()`
        3. Load all PageScore records for this audit where was_scored=True
        4. For each page, call `_generate_page_recommendations()`
        5. Generate negative sentiment recommendations (criterion_id="SENTIMENT", page_url=None, category="sentiment") -- query MentionSentiment records for this audit, find negative ones, create a recommendation per negative mention with the quote and a fix suggestion
        6. Sort all recs by priority then gap_score descending
        7. db.add all recs, db.flush()
        8. Return rec list

      - `_compute_competitor_averages(self, comp_audits)` -> dict[str, Optional[float]]: Average per-category scores across completed competitor audits. Categories: crawlability, content_structure, structured_data, authority. Return None for categories with no data.

      - `_generate_page_recommendations(self, audit_id, user_id, page_score, comp_avgs)`:
        1. Load CriterionResult records for this page_score where checked=True
        2. For each criterion: lookup benchmark in CRITERION_RESEARCH_MAP (or DEFAULT_BENCHMARK)
        3. Skip if criterion.score >= threshold
        4. Compute gap_score: if comp_avg for category exists, use comp_avg - criterion.score; otherwise use threshold - criterion.score
        5. Skip if gap_score < 10
        6. Classify priority via `_classify_priority(impact_pct, gap_score)`
        7. Compute rec_hash via `_compute_rec_hash(criterion_id, page_url)`
        8. Look up prior status via `_lookup_prior_status(rec_hash, user_id)`
        9. Build summary string: "{criterion_name} -- {page_url_path}: {human_summary}. {impact_label} ({evidence_source})"
        10. Build action_steps list from criterion technical_detail + research guidance
        11. Look up code_snippet from CRITERION_SNIPPETS
        12. Create AuditRecommendation instance
        Return list of recs for this page

      - `_classify_priority(impact_pct, gap_score)`: HIGH if gap_score >= 50 OR (impact_pct >= 200 AND gap_score >= 30). MEDIUM if impact_pct >= 120 AND gap_score >= 20. LOW otherwise.

      - `_lookup_prior_status(rec_hash, user_id)`: Query most recent AuditRecommendation with matching hash and done/dismissed status for this user's audits. Return status string or None.

      - `_build_summary(criterion, benchmark, comp_avg, page_url)`: Build user-facing one-liner. Include competitor comparison if comp_avg exists.

      - `_build_action_steps(criterion, benchmark)`: Build list of action step strings from criterion.technical_detail and research guidance.

    **2. `backend/app/services/sentiment_service.py`** -- SentimentService:

    Follow 08-RESEARCH.md Pattern 3.

    - `class SentimentService`:
      - `SENTIMENT_MODEL = "gemini/gemini-2.5-flash"`
      - `__init__(self, db: Session)`

      - `classify_mention_sentiment(self, context_quote: str) -> dict`:
        - Guard: if not settings.GEMINI_API_KEY, return {"sentiment": "neutral", "confidence": 50}
        - Call litellm.completion() with:
          - model=self.SENTIMENT_MODEL
          - api_key=settings.GEMINI_API_KEY  (CRITICAL: must pass explicitly, pydantic-settings does NOT populate os.environ)
          - response_format={"type": "json_object"}
          - temperature=0.0
          - System prompt: classify brand mention as positive/negative/neutral, return JSON with sentiment and confidence
          - User prompt: the context_quote
        - Parse response JSON, return dict with sentiment and confidence
        - On error: return {"sentiment": "neutral", "confidence": 50}

      - `analyze_audit_sentiments(self, audit_id: str) -> list[MentionSentiment]`:
        - Query BrandMention joined with EngineResponse.engine, joined with AuditQuery, filtered by audit_id
        - Guard: if no mentions, return empty list
        - For each (mention, engine): call classify_mention_sentiment, create MentionSentiment record, add to db
        - Wrap each classification in try/except, log warning on failure, continue with next mention
        - db.flush()
        - Return list of MentionSentiment records

      - `get_per_engine_summary(self, audit_id: str) -> dict[str, dict]`:
        - Single aggregating SQL query using func.count, group by engine + sentiment
        - Build summary dict: {engine_name: {positive: N, negative: N, neutral: N, total: N, dominant: "positive"|...}}
        - Dominant = sentiment with highest count
        - Return summary dict
