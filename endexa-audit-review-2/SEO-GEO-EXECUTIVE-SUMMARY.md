### 3. Audit Methodology Differences

**Crawl-Only (Current Standard):**
- Simulates search engines
- Detects runtime issues (page rendering, Core Web Vitals)
- Cannot see code quality
- Best for: SMBs, startups

**Repo-Access (Emerging):**
- Analyzes source code + build pipeline
- Detects code quality, ESLint issues, unused assets
- Cannot see runtime behavior
- Best for: Enterprise (50+ repositories)

**Winner:** Hybrid approach (both methods) = most valuable for enterprises.

### 4. Enterprise Pain Points

**Scaling Challenges:**
- Managing 10K+ URLs across multiple repositories
- Content duplication across teams kills domain authority
- CRM/platform integration (Salesforce, HubSpot) gaps
- Cross-team coordination friction
- Authority fragmentation across subdomains/regions

**Market Opportunity:** Tools that solve multi-repo governance at scale will dominate enterprise.

### 6. AI Engine Citation Patterns

| Engine | Architecture | Citation Default | Optimization Focus |
|--------|--------------|------------------|-------------------|

**Key Insight:** Perplexity-first for citations; ChatGPT for authority; Claude requires user context.
